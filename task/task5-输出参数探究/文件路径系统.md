也就是说：

S1 是大类别
L1 是小类别
视频序号 是第几个样本，比如 1
num.mp4 放这个样本的视频文件
num.npz 放这个样本的深度文件
video.json 放这个样本的视频级信息，比如 duration_s、fps、num_frames、gravity、cameras
object_static.json 放这个样本所有物体的静态属性，物体包含地面、墙、斜面、障碍物和动态物体
dynamic/ 下面按帧存每一帧的动态信息
每一帧里有：
帧图片 是当前帧的图像
force_matrix.json 放当前帧的物体间作用力矩阵，最多 9 个物体时用 10*10 二维矩阵
object_dynamicjson/ 放当前帧每个 object 的动态 json
object_segment/ 放当前帧每个 object 的 segmentation npz
