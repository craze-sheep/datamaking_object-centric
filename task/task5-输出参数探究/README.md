# Task5：输出参数探究

本目录回答三个问题：

1. 物体的哪些参数、属性、事件需要记录下来？
2. 这些字段属于输入配置、仿真观测，还是后处理标签？
3. 应该用什么结构记录，方便之后训练、筛选、复现和排错？

建议采用两层输出：

- 每个视频一个 `metadata.json`：记录场景配置、物体属性、事件标签、可见性和过滤结果。
- 每个视频一个可选 `states.npz` 或 `states.hdf5`：记录逐帧状态，用于精确分析轨迹、碰撞和调试。

当前建议文档：

- [输出参数记录规范.md](输出参数记录规范.md)：统一 schema、字段定义、记录方法。
- [S1-S8事件标签清单.md](S1-S8事件标签清单.md)：每类场景必须记录的事件和派生标签。
- [生成脚本落地设计.md](生成脚本落地设计.md)：细化到 object/event/state/quality check 的脚本实现口径。
- [样例_metadata.json](样例_metadata.json)：单个视频 metadata 的推荐形状。

核心原则：

- 输入配置必须完整记录，保证任何视频可复现。
- 事件标签必须来自仿真或后处理计算，不能只从采样参数推断。
- 时间字段同时记录 `time` 和 `frame`，避免 12fps 量化导致歧义。
- 碰撞类场景必须记录 contact sequence，负样本必须记录为什么没有碰撞。
- 视觉边界样本必须记录 visible-area/left-visible-area，不能只靠人工看视频。
