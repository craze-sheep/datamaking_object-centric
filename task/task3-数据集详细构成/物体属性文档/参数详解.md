### 单位：
- 长度：m
- 质量：kg
- 时间：s
- 线速度：m/s
- 角速度：rad/s
- 角度：rad

### JSON 结构
所有物体类型共用 object_static.json，14 个字段：
- object_id, segmentation_id, object_type, static
- radius, size, height（几何参数，按类型填不同值）
- mass
- lateralFriction, rollingFriction, spinningFriction, restitution
- color_name, rgba

### 通用物体参数
- object_type（物体类型）：[ground,sphere,cube,cylinder,ramp,wall]
- static（是否静态）：ground/ramp/wall=true，sphere/cube/cylinder=false
- mass（质量）：动态物体取值，静态物体不作为变化变量
- initial_position（初始位置）
- initial_quaternion（初始姿态）：默认值 [1,0,0,0]
  - Kubric 格式：[w,x,y,z]
- initial_velocity（线速度）：动态物体取值，静态物体 [0,0,0]
- initial_angular_velocity（角速度）：动态物体取值，静态物体 [0,0,0]
- restitution（恢复系数）：[0,0.1,0.3,0.5,0.8,1]
- lateralFriction（滑动摩擦系数）：[0,0.25,0.5,0.75,1,1.5,2,3]
- rollingFriction（滚动摩擦）：[0,0.001,0.005,0.007,0.01,0.05,0.1,0.2,0.3,0.5]
- spinningFriction（自旋摩擦）：[0,0.003,0.005,0.008,0.03,0.08,0.18,0.28,0.48]
- color（颜色）

### 几何参数（按类型）

#### ground（地面）
- radius：null
- size：[(4.0, 4.0, 0.08), (8.0, 6.0, 0.08), (9.0, 6.0, 0.08), (10.0, 5.0, 0.08), (16.0, 6.0, 0.08)]
- height：null
- static：true

#### sphere（球）
- radius：[0.18,0.22,0.28]
- size：null
- height：null
- 初始姿态通常不作为变化变量（球体几何对称）

#### cube（方块）
- radius：null
- size：[(0.18,0.18,0.18), (0.24,0.24,0.24), (0.30,0.30,0.30)]
- height：null

#### cylinder（圆柱）
- radius：[0.16,0.20,0.24]
- size：null
- height：[0.22,0.28,0.34]
- 约束：若圆柱竖直放置，z > height / 2，避免初始状态与地面穿透
- 初始姿态：
  - upright（直立）：[1, 0, 0, 0]
  - lying（躺着）：[0.7071, 0, 0.7071, 0]

#### ramp（斜面）
- radius：null
- size：[(2.4, 1.0, 0.12)]
- height：null
- static：true
- incline_angle（斜面角）：单位 rad

#### wall（墙面）
- radius：null
- size：[(0.1, 5.0, 1.2)]
- height：null
- static：true
