## 二、共用物理场景

- Ground: 9.0×6.0×0.08, frictionless(默认)
- 默认排列：A 在负 x，B 在 x=0，C 在 x=0.46 (BC 间隙 0.02m)
- 三个球半径 0.22，接触距离 = r_i + r_j

**三体链式碰撞模型**（A→B→C，等质量等大小，对心）：

```
AB碰撞：v_A' = ½(1-e)×v_A,  v_B' = ½(1+e)×v_A
BC碰撞：v_B'' = ½(1-e)×v_B', v_C' = ½(1+e)×v_B'

A追赶B的二次碰撞条件：v_A' > v_B'' 且 A-B初始距离在3s内可追上
```
