### 采样与标签
- PyBullet 可用性：当前基础动态物体使用 Sphere/Cube/Cylinder；wall 使用 static Cube。
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖；下文组合数为名义组合，实际每个 level 采样到目标数量。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 初始高度：
  - sphere：z = radius
  - cube：z = size 的 z 分量 / 2
  - cylinder：z = height / 2，默认竖直放置，圆柱轴沿 z 轴

## [简单] Level 1：恢复系数的影响（e -> 能量传递效率与末速度）
目标：学习恢复系数越大，三物体链式碰撞中的能量传递越完整，末端物体速度越大。

### ground 参数
- 使用通用固定项。

### 三物体共享参数
- object_type：[sphere]
- radius：[0.22]
- mass：[1.0]
- initial_quaternion：[[1,0,0,0]]
- initial_angular_velocity：[0,0,0]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### object_a 参数
- initial_position：
  - x：[-0.95,-0.80,-0.65]
  - y：[-0.20,0,0.20]
  - z：radius
- initial_velocity：[(1.8,0,0)]
- restitution：[1.0]

### object_b 参数
- initial_position：
  - x：[0]
  - y：同 object_a 的 initial_position 的 y 分量
  - z：radius
- initial_velocity：[0,0,0]
- restitution：[0,0.3,0.5,0.8,1.0]

### object_c 参数
- initial_position：
  - x：[0.46]
  - y：同 object_a 的 initial_position 的 y 分量
  - z：radius
- initial_velocity：[0,0,0]
- restitution：同 object_b 的 restitution

### 约束
- object_b/object_c 的 restitution 为主变量；object_a 的 restitution 固定为 1.0，使 AB、BC 两次碰撞的 effective_restitution 同步变化。
- restitution 采样权重建议：0 占 10%，0.3 占 20%，0.5 占 25%，0.8 占 25%，1.0 占 20%；保留完全非弹性极值，但避免 e=0 样本过多造成末端传递过弱的分布偏置。
- object_b 与 object_c 初始中心距 0.46m，约有 0.02m 小间隙，避免初始接触抖动。
- 两次碰撞必须按 AB -> BC 发生；未触发 BC 的样本过滤。
