## 二、共用物理场景

- Ground: 8.0×6.0×0.08, frictionless（隔离碰撞物理）
- Cube size=(0.24,0.24,0.24), 左面 x=0.43, 球半径=0.22, 球接触 x=0.21
- 5 相机视角

### 球撞方块 vs 球撞球的关键差异

方块**平面接触** → 接触法向始终垂直于方块表面（x 方向），与偏心距无关。因此：
- 无摩擦时法向冲量与 offset 无关 → 球和方块**平动速度不变**，仅方块**角速度**随 offset 变化
- 需要碰撞摩擦才能使球在偏心碰撞中获得切向偏转

## 三、各 Level 物理推导

### Level 1：恢复系数的影响

等质量对心碰撞：`v_a=½(1-e)×1.8, v_b=½(1+e)×1.8`。5 档 e 覆盖完全非弹性到完全弹性。✓

```
数量：e_b(5) × x_a(3) × y(3) × color(4)² = 720 ✓
```

### Level 2：入射速度大小的影响

speed=[1.4,1.7,2.0,2.4,2.8], v_cube=0.9×speed。speed≥1.7 方块出右边界，标签 `cube_left_visible_area` 已添加。✓

```
数量：speed(5) × x_a(3) × y(3) × color(4)² = 720 ✓
```

### Level 3：方块质量的影响

m_b=[0.3,0.5,1.0,2.0,5.0]。轻方块飞出、重方块使球反弹。公式与 S5 一致（对心碰撞与目标形状无关）。✓

```
数量：m_b(5) × v0(2) × y(3) × color(4)² = 480 ✓
```

### Level 4：物体恢复系数组合

e_a×e_b 共 9 种组合 (0.09~1.00)。✓

```
数量：e_a(3)×e_b(3) × v0(2) × x(2) × y(3) × color(4)² = 1728 ✓
```

### Level 5：碰撞偏心距（有摩擦）

**参数修复后**：sphere_a.lateralFriction=1.0, cube_b.lateralFriction=0.5, offset=[-0.25~0.25]×7。

有摩擦时切向冲量 `j_t = min(μ_eff × j_n, m_eff × |v_rel_t|)` 使球获得 y 向速度 → 球偏转 + 方块旋转。

| offset | 球-面重叠 | ω_cube(v0=1.8) | 球偏转 |
|:---:|---:|---:|:---:|
| 0 | 0.34m | 0 rad/s | 无（对心基线）|
| ±0.10 | 0.24m | 8.4 rad/s | 微偏 |
| ±0.20 | 0.14m | 16.9 rad/s | 明显偏转 |
| ±0.25 | 0.09m | 21.1 rad/s | 大幅偏转 |

旧版 lateralFriction=0 → 球不偏转的问题已修复。offset 上限从 0.30 收紧至 0.25，保证重叠 ≥ 0.09m。✓

```
数量：offset(7) × v0(2) × x(2) × color(4)² = 448 ✓
```

### Level 6：入射角度与二维碰撞方向

命中条件：`|y_a + tan(angle)×(0.43-x_a) - cube_y| < 0.34`。约 50% 组合 miss，过滤后仍充足。✓

名义 2880，过滤后 ~1400 ✓

### Level 7：碰撞摩擦系数

offset=[±0.25,±0.18], lateralFriction=[0,0.2,0.5,0.8,1.0]。μ=0 为无摩擦基线，μ=1.0 切向接近清零。offset 上限从 0.28 收紧至 0.25。✓

```
数量：offset(4)×lateralFriction(5) × v0(2) × x(2) × color(4)² = 1280 ✓
```

### Level 8：方块初始姿态

quat=[face(0°), yaw_22.5°, yaw_45°]。yaw_45 时方块面倾斜 45°，球反弹角 ≈ 90°（法向偏转），是有效的形状泛化。⚠ 边角碰撞建议渲染抽检。✓

```
数量：quat(3)×v0(2)×y_a(3)×x(2)×color(4)² = 576 ✓
```

### Level 9：初始旋转球撞方块

spin_z: 接触点切向贡献 = 8×r (1.44~2.24 m/s)，与 v0=2.2 同量级。spin_y 为弱效应保留。✓

```
数量：radius(3)×ω(5)×y_b(2)×x_a(2)×color(4)² = 960 ✓
```
