# S6：球撞方块参数配置

## 全局设置
- 视频时长：3s
- 分辨率：64 x 64
- 总帧数：36 帧
- 帧率：12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,back,left,right,top]
- 样本数口径：下文样本数指物理场景配置数；若每个配置渲染 5 个相机视角，视频数 = 样本数 x 5。
- 简单 level 样本数：约 80 个
- 复杂 level 样本数：约 120 个

## 通用固定项

### ground 参数
- object_type：[ground]
- PyBullet/Kubric 实现：static Cube
- size：[(8.0,6.0,0.08)]
- initial_position：[0,0,-0.04]
- initial_quaternion：[[1,0,0,0]]
- static：true
- mass：[1.0]

- initial_velocity：[0,0,0]

### cube_b 参数

### 采样与标签
- PyBullet 可用性：当前 Kubric PyBullet wrapper 直接支持 Sphere/Cube；本任务使用 Sphere 撞 Cube。
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 初始高度：
  - sphere_a 的 z = sphere_a 的 radius
  - cube_b 的 z = cube_b 的 size 的 z 分量 / 2
- 避免初始穿透：sphere_a 与 cube_b 初始不重叠，且均不穿透 ground。
- 命中过滤：
  - 对正向/斜向撞击，使用 cube_b 在 xy 平面的膨胀包围盒做初筛。
  - 命中条件可近似为：球心轨迹与 cube_b 的 xy 投影距离 < sphere_a 的 radius。
- 通用标签：
  - first_contact_time
  - first_contact_frame
  - pre_collision_velocity_sphere
  - pre_collision_velocity_cube
  - post_collision_velocity_sphere
  - post_collision_velocity_cube
  - incident_speed_normal
  - separation_speed_normal
  - effective_restitution
  - momentum_before
  - momentum_after
  - kinetic_energy_before
  - kinetic_energy_after
  - cube_linear_displacement
  - cube_rotation_angle
  - scattering_angle_sphere
  - final_position_sphere
  - final_position_cube
  - final_linear_speed_sphere
  - final_linear_speed_cube
  - final_angular_speed_sphere
  - final_angular_speed_cube
  - sphere_left_visible_area
  - cube_left_visible_area

目标：学习恢复系数越大，球与方块碰撞后的法向分离速度越大。

- initial_angular_velocity：[0,0,0]
- restitution：[1.0]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### cube_b 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- initial_position：
  - x：[0.55]
  - y：同 sphere_a 的 initial_position 的 y 分量
  - z：size 的 z 分量 / 2
- initial_quaternion：[[1,0,0,0]]
- mass：[1.0]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0,0.3,0.5,0.8,1.0]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- cube_b 的 restitution 为主变量；sphere_a 的 restitution 固定为 1.0，使 effective_restitution 主要由 cube_b 的 restitution 决定。
- restitution 采样权重建议：0 占 10%，0.3 占 20%，0.5 占 25%，0.8 占 25%，1.0 占 20%；保留完全非弹性极值，但避免 e=0 样本过多造成分布偏置。
- 两物体 y 坐标相同，球正撞方块左侧面。
- color 只作为视觉扰动，不与恢复系数绑定。

目标：学习在固定碰撞摩擦下，偏心距越大，方块碰撞后旋转越明显，球的散射角越大。

### ground 参数

- object_type：[cube]

- impact_offset_y：[-0.25,-0.20,-0.10,0,0.10,0.20,0.25]
- initial_position：
  - x：[0.55]
  - y：impact_offset_y
  - z：size 的 z 分量 / 2
- initial_quaternion：[[1,0,0,0]]
- mass：[1.0]

- color：[red,blue,yellow,green]

### 约束
- impact_offset_y 为主变量。
- sphere_a 的 friction 固定为 1.0，cube_b 的 friction 固定为 0.5，确保偏心碰撞存在切向冲量；否则方块平面接触的法向固定，球不会因 offset 自然偏转。
- |impact_offset_y| <= 0.25，保证球-面重叠量至少 0.09m，避免极端擦边碰撞。
- offset=0 为对心碰撞基线。
