# S2：单物体水平面滑动参数配置

## 全局设置
- 视频时长：3s
- 分辨率：128 x 128
- 总帧数：36 帧，12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,top,left]
- 样本数口径：下文数量按物理场景配置计算；若渲染 3 个视角，视频数 = 物理配置数 x 3。
- 简单 level：约 80 个物理配置
- 复杂 level：约 120 个物理配置

## 通用固定项
- ground size：[(16.0,6.0,0.08)]
  - 说明：x 方向半长 8m，覆盖 L6 中 v0=3.0m/s、低摩擦/滚动场景在 3s 窗口内的水平滑行，避免物体滑出有限地面后自由下落。
- restitution：[0]
- lateralFriction：[1.0]
- initial_angular_velocity：[0,0,0]
- color：[red,blue,yellow,green]
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 初始高度：
  - cube：z = size 的 z 分量 / 2
  - sphere：z = radius
  - cylinder upright：z = height / 2
  - cylinder lying：z = radius
- 通用标签：
  - stop_time
  - stop_frame
  - travel_distance
  - displacement_vector
  - final_position
  - final_linear_speed
  - final_angular_speed
  - effective_lateral_friction
  - rolling_transition_time
  - is_static_at_end

## [简单] Level 1：滑动摩擦的定性影响（mu -> 停止距离）
目标：学习滑动摩擦越大，停止时间和停止距离越小。

### 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- mass：[1.0]
- initial_position：
  - x：[-0.2,0,0.2]
  - y：[-0.2,0,0.2]
  - z：0.12
- initial_velocity：[(2.0,0,0)]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.15,0.25,0.35,0.50,0.60]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- lateralFriction 为主变量。
- 不取 lateralFriction = 0，避免 3s 内几乎不停。
- 不取 lateralFriction > 0.60，避免高摩擦停止过程压缩到 4 帧以内。
- v0=2.0m/s 时，最高摩擦 0.60 的理论停止时间约 4.1 帧，作为最紧凑的高摩擦可见样本。

## [简单] Level 2：初速度大小的影响（v0 -> 停止距离）
目标：学习同一摩擦下初速度越大，停止距离越长。

### 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- mass：[1.0]
- initial_position：[0,0,0.12]
- initial_velocity：[(1.0,0,0),(1.3,0,0),(1.6,0,0),(1.9,0,0),(2.2,0,0),(2.5,0,0),(2.8,0,0),(3.0,0,0)]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.3,0.45,0.6]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- initial_velocity 的 x 分量为主变量，lateralFriction 作为配对扰动变量。
- v0 不低于 1.0m/s，保证最低速度也有可见位移。

## [简单] Level 3：质量无关性验证（质量不影响滑动距离）
目标：验证理想库仑摩擦下，质量不影响水平滑动距离。

### 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- mass：[0.3,0.5,1.0,2.0,5.0]
- initial_position：[0,0,0.12]
- initial_velocity：[(1.0,0,0),(2.0,0,0),(3.0,0,0)]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.3,0.5]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- mass 为被验证的无关变量。
- 对同一 initial_velocity 与 lateralFriction 生成完整 mass 配对组。

## [简单] Level 4：尺寸/接触面积无关性（面积不影响滑动距离）
目标：验证同一质量和摩擦下，方块尺寸/接触面积不影响滑动距离。

### 参数

- mass：[1.0]
- initial_position：[0,0,size 的 z 分量 / 2]
- initial_velocity：[(1.0,0,0),(1.4,0,0),(1.8,0,0),(2.2,0,0),(2.6,0,0)]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.3,0.45,0.6]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- size 为被验证的无关变量。
- 对同一 initial_velocity 与 lateralFriction 生成完整 size 配对组。

## [复杂] Level 5：初速度方向与二维滑动（向量减速）
目标：学习二维速度方向不改变摩擦减速大小，位移方向跟随初速度向量。

### 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- mass：[1.0]
- initial_position：[0,0,0.12]
- speed：[1.5,2.0,2.5]
- direction_degree：[0,45,90,135,180,225,270,315]
- initial_velocity：speed * [cos(direction), sin(direction), 0]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.3,0.5]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- speed 与 direction_degree 均衡覆盖。
- top 视角为关键评估视角。
- 不使用 mu=1.0，避免低 speed 场景在 2 帧内停止。

## [复杂] Level 6：球体的滑动与滚动转换（引入 rollingFriction）
目标：学习球体从纯滑动到滚动的转换，并区分 rollingFriction 对滚动阶段的影响。

### sphere 参数
- object_type：[sphere]
- radius：[0.18,0.22,0.28]
- mass：[0.5,1.0,2.0]
- initial_position：[0,0,radius]
- initial_velocity：[(2.0,0,0),(2.5,0,0),(3.0,0,0)]
- initial_angular_velocity：
  - pure_sliding：[0,0,0]
  - near_rolling：[0,-initial_velocity 的 x 分量 / radius,0]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.2,0.3]
- rollingFriction：[0,0.01,0.03,0.05,0.1]
- spinningFriction：
  - rollingFriction = 0：[0]
  - rollingFriction > 0：[0,0.003,0.005]

### cube 基线
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- mass：[1.0]
- initial_position：[0,0,0.12]
- initial_velocity：[(2.5,0,0)]
- initial_quaternion：[[1,0,0,0]]
- lateralFriction：[0.3]
- rollingFriction：[0]
- spinningFriction：[0]

### 约束
- sphere 为主任务，cube 只作为不滚动基线。
- 过滤 spinningFriction > rollingFriction 的组合。
- near_rolling 角速度方向按 +x 平移对应绕 y 轴负方向设置。
- 使用较低 lateralFriction 和较高初速度，让滑动到滚动转换至少持续约 2 帧。

## [复杂] Level 7：圆柱的滑动行为（姿态影响）
目标：学习圆柱直立/躺倒姿态，以及沿轴/垂轴方向运动对滑动和滚动行为的影响。

### 公共参数
- object_type：[cylinder]
- radius：[0.16,0.20,0.24]
- height：[0.22,0.28,0.34]
- mass：[1.0]
- lateralFriction：[0.3,0.5]
- rollingFriction：[0,0.01,0.05]
- spinningFriction：[0]

### 姿态参数
- upright：
  - initial_quaternion：[1,0,0,0]
  - initial_position：[0,0,height / 2]
  - initial_velocity：[(2.0,0,0),(0,2.0,0)]
- lying_axis_x：
  - initial_quaternion：[0.7071,0,0.7071,0]
  - initial_position：[0,0,radius]
  - initial_velocity：[(2.0,0,0),(0,2.0,0)]
- lying_axis_y：
  - initial_quaternion：[0.7071,0.7071,0,0]
  - initial_position：[0,0,radius]
  - initial_velocity：[(2.0,0,0),(0,2.0,0)]

### 约束
- upright、lying_axis_x、lying_axis_y 均衡覆盖。
- 躺倒姿态需覆盖沿轴方向和垂轴方向运动。
- rollingFriction 在三种姿态中均衡覆盖，统一使用 [0,0.01,0.05]。
