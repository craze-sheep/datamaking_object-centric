## 二、共用物理场景

- Ground: 10.0×5.0×0.08, frictionless (lateralFriction=0), 表面 z=0
- Wall: 0.10×5.00×1.20, 位于 x=1.20, y 跨度 [-2.5, 2.5], z 跨度 [0, 1.20]
- 物体初始 z = radius(sphere) 或 size.z/2(cube)，刚好触地
- initial_velocity.z = 0

**物理场景**：摩擦less地面上的滑动-撞墙。地面无摩擦是刻意设计，用于隔离墙面碰撞物理。物体碰撞前做匀速直线运动：

```
v_x = const,  v_y = const (碰撞前)
t_coll = (1.15 - radius - x_start) / v_x
```

碰撞后法向反弹 + 切向摩擦影响：

```
v_x_after = -e_eff × v_x_before     // e_eff = e_obj × e_wall
v_y_after = v_y_before - Δv_fric    // Δv_fric ∝ μ_wall
```

## 五、最终结论

墙面反弹参数配置**物理上可用**。上轮 3 个核心问题全部通过几何调整修复（地面加长 + 墙面加宽 + 最低速度提升），所有角度×位置组合均能命中墙壁，高恢复系数样本不再出界。数量全部大幅超标。可进入渲染验证阶段。

仅建议：渲染时抽检 L9 cube corner_contact 的碰撞行为，确认尖角碰撞无穿透或异常旋转。
