# Type S8 泛化负样本 — 物理合理性验证报告

## 一、总体设计

S8 共 14 个复杂 Level，无简单 Level。**所有样本均为"无碰撞"负样本**，通过随机参数采样 + 物理引擎过滤 (dynamic_dynamic_contact_count=0) 保留有效样本。每个 Level 目标约 120 个物理配置。

设计思路不同于 S1-S7 的结构化参数采样，而是**约束引导 + 仿真过滤**的范式。

---

## 二、各 Level 物理验证

### Level 1：空间分离（平行轨迹错开）

**机制**：物体分配不同 y-lane，|Δy| ≥ 0.60，min_pairwise_distance ≥ 0.12。

**验算**：同向物体在平行 lane 上永远不相遇。反向物体在最近 x 接近处，y 距离 = lane 间距。

**lane 间距已修复为 0.60，对最大半径充足**：

```
最大接触距离 = 0.28 + 0.28 = 0.56 < 0.60
```

当两个 r=0.28 的球在相邻 lane 上反向运动时，最近距离 = 0.60 > 0.56，不会因最大半径组合直接碰撞。

物理原理正确（平行不相交 → 不碰撞），且当前 lane 间距已降低大半径反向运动样本的过滤损耗。✓

---

### Level 2：时间分离（先后经过同一点）

**机制**：多物体指向共享区域中心，到达时间差 ≥ 0.30s。

**验算**（最苛刻：speed=0.8, time_gap=0.30）：
- 物体 A 在中心 [0,0] 时刻，物体 B 距中心 = 0.8×0.30 = 0.24m
- 垂直通过时最近距离 = 0.24m，但 2r=0.44m → 0.24 < 0.44

⚠ **低速度 + 最小时间差组合可能撞上**。同样由过滤兜底，不会产出错误样本。但建议采样时 speed 与 time_gap 做关联：低速度搭配大 time_gap。

物理原理正确（不同时刻经过同一点不碰撞）。✓

---

### Level 3：速度差异（追不上）

**子场景 A — 同向追不上**：rear_speed < front_speed，初始间距 ≥ 0.80m。地面无摩擦 → 匀速 → 后方永追不上。**必然无碰撞** ✓

**子场景 B — 交叉错开**：到达交叉点时间差 ≥ 0.25s。类似 L2，由过滤兜底。✓

---

### Level 4：随机参数全空间过滤

**机制**：1~6 个物体，参数全部随机采样，仿真后仅保留无碰撞样本。

纯过滤方案，物理正确性由引擎保证。object_count=1 天然无碰撞（限制 ≤15%）。✓

---

### Level 5：障碍物阻隔

**机制**：障碍物（vertical_bar/horizontal_bar/block）将左右两侧物体分隔。

**验算**：
- 障碍物高 0.90m，物体最高接触高度 0.28m（sphere radius 0.28）
- vz=0 → 物体无法翻越
- 约束：障碍物高度 > 2×最大物体高度 = 0.56m → 0.90 > 0.56 ✓

物体只能撞墙反弹，无法到达对侧。**阻碍必然有效** ✓

```
数量：物体会撞障碍物反弹，但 dynamic_dynamic_contact 保持为 0 ✓
```

---

### Level 6：摩擦停止

**机制**：物体在到达碰撞点前因地面摩擦停下。

**验算**（最不利：μ=0.5, v=1.0, m=2.0）：

```
d_stop = v² / (2μg) = 1.0 / (2×0.5×9.8) = 0.102m
```

物体从 x=±2.2 出发，距中心 2.2m。d_stop = 0.102m << 到达对方所需距离。**必然在相遇前停止** ✓

约束预筛 `d_stop < 到潜在碰撞点距离 - 0.25m`，大幅降低过滤损耗。✓

⚠ μ=2.0 的物理真实性：地面摩擦系数 2.0 在现实世界罕见（接近橡胶-on-橡胶的极限值），但对物理引擎无影响。可接受。

---

### Level 7：三维高度错开

**机制**：物体初始 z 高度不同 [0.22, 0.80, 1.20, 1.60]，vz ∈ [-0.4, 0, 0.4]。

⚠ **高度分离是暂时的**：gravity=[0,0,-9.8] 存在。

- 高空物体 (z=1.60, vz=0)：落地时间 = sqrt(2×1.38/9.8) = 0.53s
- 之后所有物体均在 z=radius 的地面上

物体水平投影轨迹相交时，若交会时刻在 0.53s 内 → 高度错开，不碰撞；若在 0.53s 后 → 可能在地面碰撞。

**过滤兜底有效**，但会过滤掉"先高空错开、后地面碰撞"的样本。不产生错误正样本。✓

```
建议：降低 gravity 或去掉 gravity（让物体保持高度），可使高度分离持续整个 3s。
但当前设计保留重力更接近真实物理场景（物体终究会落地），选择合理。
```

---

### Level 8：动态隔离

**机制**：三球同速同向，间距 1.40m。接触距离 0.44m。

三球从未相互接近（同速同向 → 距离恒定）。**左右球被中间球永久隔离，必然无碰撞** ✓

物理约束干净，无需过滤兜底。设计优雅。✓

---

### Level 9：边界反弹但总错过

**机制**：2~4 球在 x=±2.2, y=±1.6 的边界盒内反复反弹。

边界大小：4.4m × 3.2m。球速度 1.0~1.8 m/s。球在 3s 内可完成多次穿越和反弹。轨迹密集交错。

大量"险些碰撞"的情景被制造出来。过滤保留未碰撞的样本。✓

⚠ 边界相对紧凑 + 多球 → 碰撞概率高 → **过滤损耗可能很大**。建议初始采样量按目标的 3~5 倍生成。

---

### Level 10：极小物体擦肩

**机制**：radius=[0.05,0.08,0.12]，near-miss margin [0.02, 0.08]。

⚠ **64px 分辨率下可见性问题**：

| radius | 直径(cm) | 像素(64px/2m FOV) |
|:---:|---:|:---:|
| 0.05 | 10 | **1.6 px** |
| 0.08 | 16 | 2.6 px |
| 0.12 | 24 | 3.8 px |

r=0.05 的球在画面中仅 ~1.6 像素直径。margin=0.02m = **0.64 像素**。模型完全无法从视觉上区分"擦肩而过"与"刚好触碰"。

但标签中记录了 min_pairwise_distance 等物理量，模型可从**物体速度不变**（无碰撞冲量）推断未碰撞，而非仅靠视觉间距。

当前参数配置已注明：r=0.05 是物理标签/速度不变特征的极限擦肩样本；如果后续只做纯视觉判别评估，可另行将最低半径提升至 0.10 或提高分辨率。

---

### Level 11：旋转错开（方块/圆柱）

**机制**：非球形物体（cube/cylinder）带旋转，姿态变化改变接触几何，使原本会碰的物体错开。

物理正确：旋转方块的对角线长度 > 边长，在不同姿态下接触距离不同。引擎的碰撞检测自动处理旋转几何。✓

约束"最近距离 < 0.20m"保证这是近距负样本。✓

---

### Level 12：外力干预

**机制**：在 t=[0.35,0.50,0.70] 施加冲量，改变轨迹避免碰撞。反事实（无冲量）应碰撞。

**设计问题**：每个样本需**两次仿真**（有冲量 + 无反事实），计算成本翻倍。但物理设计正确。

⚠ 冲量大小固定（lateral=0.35，slow_down=0.45），需验证冲量是否足以在所有速度/位置组合下改变轨迹避开碰撞。若初始碰撞参数过于极端（如高速对撞、间距极小），冲量可能不足以避开 → 过滤。

**建议**：冲量大小与物体速度关联（如 impulse = k × m × v_approach），自适应调节。

---

### Level 13：完全静止

**机制**：多物体静止放置，间距 ≥ 接触距离 + 0.18m。v=0, ω=0。

**必然无碰撞**。最极端的负样本。✓

⚠ 需确保 ground.friction=0.5 足以防止微小初始扰动导致物体滑动。静态物体在重力 + 摩擦力下保持静止：mg×μ = 9.8×0.5 = 4.9N，足以抵抗任何合理扰动。✓

---

### Level 14：速度方向背离

**机制**：物体从中心向外辐射，dot(r_ij, v_ij) > 0 对所有物体对成立。

无摩擦地面 + 匀速 → 物体间距离单调递增 → **必然永不碰撞** ✓

约束干净。物体在 3s 内可能离场（最早 2.25s @ v=2.0），标签已记录。✓

## 四、设计评价

S8 的 14 个 Level 覆盖了**不碰撞的全部物理原因**：

| 物理维度 | 覆盖 Level |
|---|---|
| 空间分离 | L1, L5, L8 |
| 时间分离 | L2, L3-B |
| 速度关系 | L3-A, L14 |
| 摩擦停止 | L6 |
| 高度分离 | L7 |
| 边界反弹+相位 | L9 |
| 尺寸/余量 | L10 |
| 旋转姿态 | L11 |
| 外力干预 | L12 |
| 完全静止 | L13 |
| 纯随机 | L4 |

**设计亮点**：
- 过滤兜底机制保证了零假阳性（不会有碰撞样本被标记为无碰撞）
- L8（动态隔离）和 L14（速度背离）的约束可**必然保证**无碰撞，无需过滤
- L12 的反事实设计是因果推理的高级负样本

**核心风险**：
- L10 的分辨率限制：64px 下近距擦肩与碰撞在视觉上无法区分
- L1/L2/L9 的过滤损耗：需关注有效样本产出率

---

## 五、最终结论

S8 泛化负样本设计整体合理。物理引擎过滤兜底保证了所有产出样本确实无碰撞。14 个 Level 系统性地覆盖了空间、时间、速度、摩擦、高度、边界、尺寸、旋转、外力、静止、发散共 11 个维度的非碰撞场景。

主要剩余风险是 L10 的低分辨率可见性下限；其余为采样效率优化（降低过滤损耗）。
