## 全局设置
- 视频时长：3s
- 分辨率：128 x 128
- 总帧数：36 帧
- 帧率：12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,back,left,right,top]
- 样本数口径：下文样本数指物理场景配置数；若每个配置渲染 5 个相机视角，视频数 = 样本数 x 5。
- 简单 level 样本数：无
- 复杂 level 样本数：约 120 个

## [复杂] Level 1：空间分离导致的未碰撞（平行轨迹错开）
目标：学习轨迹在空间上不交汇时，即使多个物体同时运动也不会碰撞。

### ground 参数
- 使用通用固定项。

### dynamic_object 参数
- object_count：[2,3,4,5,6]
- object_type：[sphere,cube]
- radius / size：使用通用参数池
- lane_y：[-1.50,-0.90,-0.30,0.30,0.90,1.50]
- initial_position：
  - x：[-1.8,-1.4,-1.0]
  - y：每个物体分配不同 lane_y
  - z：按 object_type 接触高度
- initial_velocity：
  - speed：[0.8,1.2,1.6,2.0]
  - direction：[(1,0,0),(-1,0,0)]
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[0.8]
- lateralFriction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- 任意两条 lane 的 |delta_y| >= 0.60，大于最大球-球接触距离 0.56m，降低大半径反向运动样本的过滤损耗。
- 同向或反向速度均可，但轨迹线在 xy 平面不相交。
- 过滤条件：dynamic_dynamic_contact_count=0，min_pairwise_distance >= 0.12。

## [复杂] Level 12：力或冲量干预使物体在碰撞前转向
目标：学习外力/冲量改变轨迹，导致原本会碰撞的物体避开。

### ground 参数
- lateralFriction：[0]
- 使用通用固定项。

### dynamic_object 参数
- object_count：[2,3]
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[-1.4,1.4,0]
  - y：[0,-0.2,0.2]
  - z：radius
- initial_velocity：
  - speed：[1.0,1.4,1.8]
  - direction：初始指向潜在碰撞点
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[0.8]
- lateralFriction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### external_impulse 参数
- enabled：[true]
- target_object：[object_1,object_2]
- apply_time：[0.35,0.50,0.70]
- impulse_vector：
  - lateral_left：[0,0.35,0]
  - lateral_right：[0,-0.35,0]
  - slow_down：[-0.45,0,0]
- duration_frames：[1,2]

### 约束
- 未施加冲量的反事实轨迹应在 3s 内发生碰撞；施加冲量后 dynamic_dynamic_contact_count=0。
- 标签中记录 intervention_time、target_object、impulse_vector、counterfactual_would_collide=true。

## [复杂] Level 13：完全静止的多物体场景（所有物体速度为零）
目标：学习完全静止且有间距的场景天然无碰撞。

### ground 参数
- lateralFriction：[0.5]
- 使用通用固定项。

### dynamic_object 参数
- object_count：[2,3,4,5,6]
- object_type：[sphere,cube,cylinder]
- radius / size / height：使用通用参数池
- initial_position：
  - x：uniform[-2.0,2.0]
  - y：uniform[-1.4,1.4]
  - z：按 object_type 接触高度
- initial_quaternion：按 object_type 指定
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- mass：[0.5,1.0,2.0]
- restitution：[0.5]
- lateralFriction：[0.5]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- 任意两物体初始最近距离 >= 接触距离 + 0.18m。
- total_contact_count=0，所有物体 final_linear_speed=0。
- 该 level 不允许外力、边界碰撞或初始重叠。

## [复杂] Level 14：速度方向严格背离的多个物体
目标：学习相对速度始终分离时，不会发生追及或交叉碰撞。

### ground 参数
- lateralFriction：[0]
- 使用通用固定项。

### dynamic_object 参数
- object_count：[3,4,5,6]
- object_type：[sphere,cube]
- radius / size：使用通用参数池
- initial_position：
  - center_cluster_radius：[0.20,0.35,0.50]
  - x/y：围绕场景中心均匀分布，且无初始重叠
  - z：按 object_type 接触高度
- initial_velocity：
  - speed：[0.8,1.2,1.6,2.0]
  - direction：从场景中心向外辐射
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[0.8]
- lateralFriction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- 对任意物体对 i,j，初始相对位置 r_ij 与相对速度 v_ij 满足 dot(r_ij, v_ij) > 0，表示距离正在增大。
- dynamic_dynamic_contact_count=0。
- object_left_visible_area 记录物体离开视野/地面范围情况；离开前至少保留 12 帧可见。
