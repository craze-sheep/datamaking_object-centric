## 已做自动检查

- 现有 `cases.json` 记录了每个探针 case 的仿真结果、末状态和接触计数。
- `MP4 文件` 大于 0 只说明视频文件已生成，不说明视觉质量一定合格。
- `total_contact_samples` 记录所有接触采样；落体、滑动、斜面、墙面等 static 接触主要看这一列。
- `dynamic_dynamic_contact_samples` 只统计动态物体之间的接触；S5/S6/S7 的碰撞探针应大于 0，S8 负样本应为 0。
- 视觉是否“足够清楚”仍需要人工打开视频复核，不能只靠接触计数判断。
