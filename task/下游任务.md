# SlotFormer 下游任务设计调研

## 1. SlotFormer 在整个系统里的位置

SlotFormer 的核心作用不是直接做问答、规划或分类，而是作为一个 **object-centric world model**：先把视频分解成一组物体级 slot，再学习这些 slot 随时间的演化。下游任务不直接依赖原始像素，而是依赖：

```text
视频帧
  -> 物体中心表征模型（SAVi / STEVE / Slot Attention 类模型）
  -> 每一帧的 slots: [T, N, C]
  -> SlotFormer 预测未来 slots
  -> 下游 readout / VQA / planning / evaluation head
```


其中：

- `T`：时间长度。
- `N`：slot 数量，近似对应场景中的物体、背景或工具。
- `C`：每个 slot 的隐向量维度。
- SlotFormer 学到的是“物体表征空间里的动力学”，下游任务再把这些 rollout slots 转成答案、成功率、碰撞判断或规划评分。

官方代码中明确涉及的任务包括：

| 任务 | 数据集 | SlotFormer 的作用 | 下游头/评估方式 |
|---|---|---|---|
| 视频预测 | OBJ3D、CLEVRER | 根据 burn-in slots 预测未来 slots，再解码成帧、mask、bbox | 图像质量 + 物体轨迹指标 |
| CLEVRER VQA | CLEVRER | 先 rollout 未来 slots，再给 VQA 模型 Aloe | 描述、解释、预测、反事实问答准确率 |
| Physion VQA | Physion | rollout 未来 slots，判断目标物体是否接触 | binary readout，输出是否接触 |
| PHYRE 规划 | PHYRE | 作为 world model 模拟候选动作后果 | success classifier 排序动作，计算 AUCCESS |

## 2. 任务一：视频预测 Video Prediction

### 2.1 任务定义

给定前几帧视频或前几帧 slots，预测后续若干帧的物体状态和图像结果。

在 SlotFormer 的 CLEVRER 配置中，典型设置是：

- 输入 `6` 个 burn-in frames / slots。
- 预测后续 `10` 个 rollout frames / slots。
- 对 CLEVRER 会设置 `frame_offset=2`，即隔帧采样。
- 测试时会 rollout 到更长序列，例如 CLEVRER 测试使用 `48` 帧。

对应本地代码：

- `SlotFormer-master/slotformer/video_prediction/configs/slotformer_clevrer_params.py`
- `SlotFormer-master/slotformer/video_prediction/test_vp.py`
- `SlotFormer-master/slotformer/video_prediction/vp_utils.py`

### 2.2 输入输出形式

输入：

```text
observed_slots: [B, T_obs, N, C]
```

输出：

```text
pred_slots: [B, T_pred, N, C]
recon_combined: [B, T_pred, 3, H, W]
masks: [B, T_pred, N, 1, H, W]
pred_bbox: [B, T_pred, N, 4]
```

这里的关键是：SlotFormer 先预测 slot，再通过对象中心模型的 decoder 重建未来图像、mask 和 bbox。

### 2.3 评估指标

视频预测任务分两层评估。

图像层指标：

- `MSE`：像素误差。
- `PSNR`：峰值信噪比。
- `SSIM`：结构相似度。
- `LPIPS / perceptual_dist`：感知距离。

物体层指标：

- `ARI`：预测分割与 GT 分割的聚类一致性。
- `FG-ARI`：只看前景物体的 ARI。
- `mIoU`：预测 mask 与 GT mask 的 IoU，使用 Hungarian matching 匹配物体。
- `AP / AR`：由 mask 转 bbox 后计算检测 precision / recall。

### 2.4 对我们数据集的意义

如果我们做“机械臂推球/踢球/碰撞方块”数据集，视频预测可以作为最基础的下游任务：

```text
给定前 K 帧：
机械臂/推杆刚开始运动，小球尚未碰撞目标

模型需要预测：
小球轨迹、接触时刻、目标方块是否移动、后续位置、mask/bbox 轨迹
```

推荐标注：

- 每帧 RGB。
- 每帧 instance mask。
- 每帧 bbox。
- 每个物体的 `position / velocity / angular_velocity`。
- 关键事件：`push_start`、`contact_arm_ball`、`contact_ball_target`、`target_motion_start`。

推荐评估：

- 图像预测：`MSE / SSIM / LPIPS`。
- 物体轨迹：`bbox L2`、`mask mIoU`、`position error`。
- 事件预测：接触时刻误差、是否成功碰撞目标、目标位移误差。

## 3. 任务二：CLEVRER 风格 VQA

### 3.1 任务定义

CLEVRER VQA 是 SlotFormer 最重要的推理类下游任务之一。它不是单纯看当前帧，而是要基于物体运动、碰撞和因果链回答问题。

CLEVRER 问题分为四类：

| 问题类型 | 形式 | 需要的能力 |
|---|---|---|
| Descriptive | 开放式分类 | 当前/已发生事件识别 |
| Explanatory | 多选 | 解释为什么某事件发生 |
| Predictive | 多选 | 预测未来会发生什么 |
| Counterfactual | 多选 | 假设移除/改变物体后会怎样 |

本地代码中对应：

- `SlotFormer-master/slotformer/clevrer_vqa/datasets/clevrer.py`
- `SlotFormer-master/slotformer/clevrer_vqa/models/aloe.py`
- `SlotFormer-master/slotformer/clevrer_vqa/configs/aloe_clevrer_params-rollout.py`

### 3.2 SlotFormer 如何参与

流程如下：

```text
CLEVRER 视频
  -> SAVi/STO-SAVi 提取 slots
  -> SlotFormer rollout 未来 slots
  -> 保存 rollout_clevrer_slots.pkl
  -> Aloe VQA 模型读取 observed + rollout slots
  -> 输入问题 tokens 和候选答案 tokens
  -> 输出答案
```

也就是说，SlotFormer 并不直接回答问题；它提供“未来物体状态”。VQA 模型再基于这些状态做语言/事件推理。

### 3.3 训练和评估

训练方式：

- 先训练 object-centric slot encoder。
- 提取所有视频 slots。
- 训练 SlotFormer 学习 slot dynamics。
- 用训练好的 SlotFormer rollout 未来 slots。
- 用 rollout slots 训练 Aloe VQA 模型。

评估方式：

- `descriptive_acc`
- `explanatory_acc`
- `predictive_acc`
- `counterfactual_acc`
- `multiple-choice_acc`

多选题要求一个问题的所有候选选项都判断正确，才算该问题正确。

### 3.4 对我们数据集的意义

我们可以把机械臂推球数据集设计成 CLEVRER 风格问题，但问题内容从“几何体碰撞”扩展到“动作-受力-接触-结果”的因果链。

示例问题：

| 类型 | 示例问题 | 需要标注 |
|---|---|---|
| Descriptive | “机械臂是否接触了红球？” | 接触事件、物体 ID |
| Descriptive | “蓝色方块最终是否移动？” | 目标位移 |
| Explanatory | “为什么红球撞到了蓝色方块？” | 动作方向、球轨迹、碰撞链 |
| Predictive | “如果机械臂继续向右推，红球会先碰到哪个物体？” | 未来事件序列 |
| Counterfactual | “如果推力减半，蓝色方块还会移动吗？” | 可控物理参数和反事实仿真 |
| Counterfactual | “如果移除黄色障碍物，红球会撞到目标吗？” | 反事实场景 |

推荐生成的问题模板：

```text
描述类：
- 哪个物体被机械臂直接推动？
- 红球最终是否接触目标方块？
- 第一次接触发生在哪两个物体之间？

解释类：
- 为什么目标方块发生移动？
- 哪个中间物体导致目标物体改变方向？
- 哪个接触事件最直接导致了最终成功？

预测类：
- 机械臂推球后，球会先撞到 A 还是 B？
- 目标方块是否会在第 N 帧前移动？
- 球最终会停在目标区域内吗？

反事实类：
- 如果推力方向改为 +Y，是否还能击中目标？
- 如果球质量增加一倍，目标方块是否还会移动？
- 如果摩擦系数降低，球是否会越过目标区域？
```

## 4. 任务三：Physion 风格接触预测 VQA

### 4.1 任务定义

Physion VQA 的任务更简单但很适合物理数据集：判断两个目标物体在未来是否会发生接触。

官方 SlotFormer 代码里，Physion readout 的注释明确说明：模型目标是预测两个目标物体是否会 contact。它使用所有 slot pair 的关系特征，并在时间维度上做 max，因为只要任意时刻接触，答案就是 yes。

对应本地代码：

- `SlotFormer-master/slotformer/physion_vqa/models/readout.py`
- `SlotFormer-master/slotformer/physion_vqa/configs/readout_physion_params.py`
- `SlotFormer-master/docs/physion.md`

### 4.2 SlotFormer 如何参与

流程：

```text
Physion training subset
  -> 训练 SlotFormer dynamics

Physion readout/test subset
  -> SlotFormer rollout slots
  -> train binary readout on readout subset labels
  -> evaluate binary readout on test subset labels
```

readout 输入：

```text
slots: [B, T, N, C]
```

readout 做的事：

1. 枚举同一帧内所有 slot pair。
2. 拼接两个 slot，得到 pair representation。
3. 用 linear layer 计算 pair relation。
4. 对所有 pair 做 `sum / mean / max` 聚合。
5. 对所有时间做 max 聚合。
6. 输出一个 binary logit：是否发生接触。

### 4.3 评估指标

- binary cross entropy loss。
- 不同阈值下的 accuracy，例如 `acc_0.10 / acc_0.30 / acc_0.50 / acc_0.70 / acc_0.90`。
- 最终通常报告最佳阈值或固定阈值下的准确率。

### 4.4 对我们数据集的意义

这是最适合我们第一阶段实现的下游任务，因为它比 CLEVRER VQA 简单，不需要复杂语言模板，但能够检验模型是否理解物体接触和碰撞后果。

推荐任务：

```text
输入：前 K 帧或前 K 帧 slots
输出：未来 T 帧内是否发生指定接触
```

可设计成多个二分类：

- `arm_contacts_ball`：机械臂是否接触球。
- `ball_contacts_target`：球是否接触目标方块。
- `ball_contacts_obstacle`：球是否撞到障碍物。
- `target_moves`：目标方块是否发生显著位移。
- `success`：是否完成任务，例如球把目标方块推入指定区域。
- `high_force_contact`：接触力是否超过阈值。

标签可以由 Kubric/PyBullet 的 collision events 自动生成：

```text
contact_event = {
  frame,
  object_a,
  object_b,
  contact_position,
  contact_normal,
  normal_force
}
```

然后转成：

```text
label = any(
  event.object_a == "ball" and
  event.object_b == "target" and
  event.frame in future_window
)
```

## 5. 任务四：PHYRE 风格动作规划 Planning

### 5.1 任务定义

PHYRE planning 是 SlotFormer 最接近“世界模型用于决策”的下游任务。模型需要在很多候选动作中选择最可能成功的动作。

官方流程：

```text
候选动作
  -> 根据动作生成初始场景
  -> SAVi 从初始帧提取 slots
  -> SlotFormer rollout 未来 slots
  -> success classifier 判断该动作是否成功
  -> 对所有候选动作排序
  -> 评估前 N 次尝试是否成功
```

对应本地代码：

- `SlotFormer-master/slotformer/phyre_planning/test_phyre_planning.py`
- `SlotFormer-master/slotformer/phyre_planning/models/readout.py`
- `SlotFormer-master/docs/phyre.md`

### 5.2 SlotFormer 如何参与

SlotFormer 在这里相当于一个可查询的物理模拟器：

```text
action a_i
  -> initial observation o_0(a_i)
  -> slot_0
  -> SlotFormer(slot_0) = predicted future slots
  -> success_classifier(predicted future slots)
  -> score(a_i)
```

然后对所有动作按 `score(a_i)` 排序，优先尝试得分最高的动作。

### 5.3 Readout / Classifier 结构

PHYRE readout 是一个 Transformer-based binary classifier：

- 输入多个时间步的 slots。
- 只选择部分时间步，例如 `sel_slots=[0, 3]`。
- 对时间和 slot 加 positional encoding。
- 拼接 `[CLS]` token。
- Transformer encoder 做关系推理。
- MLP 输出 success logit。

### 5.4 评估指标

PHYRE 常用 `AUCCESS`：

- 对每个任务，模型给所有候选动作打分。
- 按分数从高到低尝试。
- 统计前 `1..100` 次尝试中是否成功。
- 用加权面积得到 AUCCESS。

这个指标适合衡量“模型是否能把好动作排到前面”。

### 5.5 对我们数据集的意义

我们的机械臂数据集可以设计成更贴近机器人控制的 planning：

```text
给定：
- 初始场景
- 目标，例如让球击中蓝色方块，或让目标进入指定区域
- 候选动作集合

模型需要：
- 预测每个动作的物理后果
- 选择最可能成功的动作
```

候选动作可以参数化为：

```text
action = {
  tool_type: "robot_arm" / "pusher" / "kicker",
  contact_object: "ball",
  force_magnitude: float,
  force_direction: [x, y, z],
  contact_point: [x, y, z],
  duration: float,
  start_time: int
}
```

第一阶段可以先离散化动作：

| 参数 | 离散候选 |
|---|---|
| 推力方向 | `+X, -X, +Y, -Y, diagonal` |
| 推力大小 | `small, medium, large` |
| 受力点 | `center, left, right, top` |
| 持续时间 | `short, medium, long` |
| 目标 | `hit target, avoid obstacle, stop in region` |

成功标签：

```text
success = target_moved_distance > threshold
success = ball_enters_goal_region
success = ball_contacts_target and target_not_contacts_obstacle
```

这样就能把 SlotFormer 用作 action ranking 的 world model。

## 6. SlotFormer 下游任务之间的关系

可以把四类任务按难度分层：

| 层级 | 任务 | 需要的数据标注 | 难度 | 适合阶段 |
|---|---|---|---|---|
| L1 | 视频预测 | RGB、mask、bbox、slots | 中 | 第一阶段 |
| L2 | 接触预测 | collision events、接触标签 | 中 | 第一阶段 |
| L3 | 事件/VQA | 问题模板、答案、事件图 | 较高 | 第二阶段 |
| L4 | 动作规划 | 候选动作、成功标签、目标定义 | 高 | 第三阶段 |
| L5 | 反事实推理 | 可重复仿真的参数化场景 | 最高 | 第三阶段后 |

其中最推荐的实现顺序是：

```text
1. 视频预测：验证 SlotFormer 能不能学到物体运动。
2. 接触预测：验证模型是否能预测碰撞/接触。
3. 成功预测：判断推球是否达成目标。
4. VQA：把事件标签包装成问题答案。
5. 规划：枚举候选动作，用模型预测后果并排序。
6. 反事实：改变力/质量/摩擦/障碍物，比较结果变化。
```

## 8. 建议我们最终做的下游任务

### 8.1 必做任务

**任务 A：未来视频 / mask / bbox 预测**

目标：检验 SlotFormer 是否能预测物体运动和碰撞后轨迹。

输入：

```text
前 6 帧 RGB 或 slots
```

输出：

```text
未来 10/20/40 帧 RGB、mask、bbox、position
```

指标：

```text
MSE, SSIM, LPIPS, mIoU, bbox error, position error
```

**任务 B：未来接触预测**

目标：判断模型是否理解“推 -> 球动 -> 碰撞 -> 目标动”的事件链。

输入：

```text
前 K 帧 slots
```

输出：

```text
未来是否发生 ball-target contact
未来是否发生 high-force contact
未来是否成功完成目标
```

指标：

```text
accuracy, AUROC, F1, contact-time error
```

### 8.2 强烈建议任务

**任务 C：机械臂推球 VQA**

目标：让数据集具备 CLEVRER 式可解释评测。

问题模板：

```text
红球是否被机械臂推动？
球为什么撞到蓝色方块？
如果推力变小，目标方块是否还会移动？
哪个物体最先与球接触？
```

指标：

```text
descriptive_acc, explanatory_acc, predictive_acc, counterfactual_acc
```

**任务 D：动作规划**

目标：测试 SlotFormer 能否作为 world model 选择动作。

输入：

```text
初始场景 + 候选动作集合
```

输出：

```text
候选动作成功概率排序
```

指标：

```text
Top-1 success, Top-5 success, AUCCESS
```

### 8.3 进阶任务

**任务 E：反事实物理推理**

目标：测试模型是否真正捕捉质量、摩擦、推力和碰撞关系。

反事实变量：

- 推力大小。
- 推力方向。
- 受力点。
- 球的质量。
- 球/地面的摩擦系数。
- 恢复系数。
- 障碍物是否存在。

问题：

```text
如果推力方向改为 +Y，是否仍会碰到目标？
如果球质量加倍，目标移动距离会变大还是变小？
如果受力点偏左，球是否会产生明显旋转？
```

指标：

```text
counterfactual_acc, delta_position_error, event_sequence_accuracy
```

## 9. 和我们项目的具体结合方式

对于当前项目，建议把下游任务写进整体流程：

```text
阶段 1：Kubric/PyBullet 生成物理视频
  - RGB
  - mask
  - depth
  - bbox
  - object states
  - collision events
  - action params

阶段 2：训练 object-centric encoder
  - SAVi / STEVE / Slot Attention
  - 提取 slots

阶段 3：训练 SlotFormer
  - 输入 observed slots
  - 预测 future slots

阶段 4：下游任务
  - 视频预测
  - 接触预测
  - 成功预测
  - VQA
  - 动作规划
  - 反事实推理
```

最小可行版本：

```text
1. 只做 pusher 推球，不先做真实机械臂。
2. 每个样本保存 action 参数：方向、大小、受力点、持续时间。
3. 保存 collision events。
4. 先做二分类：ball 是否撞到 target。
5. 再做视频预测和 VQA。
6. 最后扩展到候选动作规划。
```

这样设计的好处是：SlotFormer 的下游任务不会只停留在“视频好不好看”，而是能真正评估物体关系、碰撞因果、动作后果和反事实物理。
