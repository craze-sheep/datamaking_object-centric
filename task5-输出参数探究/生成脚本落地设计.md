# 生成脚本落地设计

本文档把 metadata 设计细化到“可以直接照着写生成脚本”的程度。

目标：

- 生成视频时，同时生成完整 `metadata.json`。
- 每个物体如何建模有固定字段。
- 每个事件如何记录有固定字段。
- 每类 S 场景如何从仿真状态中提取标签有明确算法。
- 后续从 PyBullet/Kubric 输出迁移时，字段名不变，只替换底层引擎实现。

## 1. 生成脚本主流程

推荐主流程：

```python
def generate_sample(config):
    sample = init_metadata(config)
    scene = build_scene(config, sample)

    state_buffer = init_state_buffer(config)
    raw_contacts = []

    for frame_idx in range(num_frames):
        for substep_idx in range(substeps_per_frame):
            apply_scheduled_impulses(scene, config, frame_idx, substep_idx, sample)
            step_physics(scene)
            raw_contacts.extend(read_contacts(scene, frame_idx, substep_idx))

        state_buffer.write(frame_idx, read_frame_state(scene))

    events = extract_events(config, state_buffer, raw_contacts)
    derived_labels = compute_derived_labels(config, state_buffer, events)
    quality_checks = run_quality_checks(config, state_buffer, events, derived_labels)

    render_all_views(scene, config, sample)
    write_metadata(sample, events, derived_labels, quality_checks)
    write_states(state_buffer)
```

核心要求：

- `sampled_params` 在仿真前写入。
- `states` 在仿真中逐帧写入。
- `events` 在仿真后从 `states + raw_contacts` 计算得到。
- `derived_labels` 只能由仿真结果或后处理得到，不能只从采样参数猜。
- `quality_checks.valid_sample` 决定样本是否进入训练索引。

## 2. Object 怎么设计

### 2.1 ObjectSpec：输入配置对象

生成脚本中建议先用一个统一 `ObjectSpec` 表示所有物体。

```python
@dataclass
class ObjectSpec:
    object_id: str
    role: str
    object_type: str
    static: bool

    # geometry
    radius: float | None = None
    size: tuple[float, float, float] | None = None
    height: float | None = None
    contact_offset: float | None = None
    collision_margin: float = 0.0
    orientation_mode: str | None = None

    # physical material
    mass: float = 1.0
    friction: float | None = None
    lateral_friction: float | None = None
    rolling_friction: float = 0.0
    spinning_friction: float = 0.0
    restitution: float = 0.0
    linear_damping: float = 0.0
    angular_damping: float = 0.0

    # initial state, metadata uses Kubric [w,x,y,z]
    initial_position: tuple[float, float, float] = (0, 0, 0)
    initial_quaternion_wxyz: tuple[float, float, float, float] = (1, 0, 0, 0)
    initial_velocity: tuple[float, float, float] = (0, 0, 0)
    initial_angular_velocity: tuple[float, float, float] = (0, 0, 0)

    # visual
    color_name: str = "gray"
    rgba: tuple[float, float, float, float] = (0.5, 0.5, 0.5, 1.0)

    # optional geometry helpers
    ramp_s: float | None = None
    ramp_y: float | None = None
    incline_angle: float | None = None
    ramp_surface_point: tuple[float, float, float] | None = None
    ramp_normal: tuple[float, float, float] | None = None
```

字段约定：

- 动态物体使用 `friction`，对应 task3 中 sphere/cube/cylinder 的摩擦字段。
- 静态接触面使用 `lateral_friction`，输出到 metadata 时写作 `lateralFriction`，对应 ground/ramp/wall/obstacle。
- 如果生成脚本内部调用 PyBullet，动态物体的 `friction` 和静态接触面的 `lateral_friction` 都会传给引擎的 `lateralFriction` 参数；但 metadata 字段仍按 task3 语义区分，避免文档层混淆。
- `friction` 与 `lateral_friction` 不要同时为同一个 object 输出；动态物体输出 `friction`，静态接触面输出 `lateralFriction`。

### 2.2 object_id 命名

必须稳定，不要用引擎 body id 当 metadata id。

推荐：

| 场景 | object_id |
|---|---|
| 地面 | `ground` |
| 墙 | `wall`、`left_wall`、`right_wall` |
| 斜面 | `ramp` |
| 障碍物 | `obstacle_0`、`obstacle_1` |
| S1 单物体 | `object` |
| S5 球撞球 | `sphere_a`、`sphere_b` |
| S6 球撞方块 | `sphere_a`、`cube_b` |
| S7 三物体 | `object_a`、`object_b`、`object_c` |
| S8 多物体 | `object_0`、`object_1`、... |

### 2.3 role 命名

`role` 不是几何类型，是物体在任务中的作用。

| role | 说明 |
|---|---|
| `ground` | 地面 |
| `ramp` | 斜面 |
| `wall` | 墙 |
| `obstacle` | 静态障碍 |
| `falling_object` | S1 落体物体 |
| `sliding_object` | S2/S3 滑动物体 |
| `moving_ball` | S5/S6 入射球 |
| `target_ball` | S5 目标球 |
| `target_cube` | S6 目标方块 |
| `driver_object` | S7 初始运动物体 |
| `relay_object` | S7 中间传递物体 |
| `terminal_object` | S7 末端物体 |
| `negative_dynamic_object` | S8 负样本动态物体 |

### 2.4 几何字段规则

必须满足：

```python
if object_type == "sphere":
    radius is not None
    contact_offset = radius

if object_type == "cube":
    size is not None
    contact_offset = size[2] / 2

if object_type == "cylinder":
    radius is not None
    height is not None
    if orientation_mode == "upright":
        contact_offset = height / 2
    else:
        contact_offset = radius

if object_type in ["ground", "wall", "ramp", "obstacle"]:
    static = True
```

### 2.5 初始穿透检查

生成前必须做：

```python
def validate_initial_geometry(objects):
    for obj in objects:
        assert obj.initial_position[2] >= obj.contact_offset - 1e-4

    for a, b in dynamic_pairs(objects):
        assert not initial_overlap(a, b)
```

不同形状的初筛可以先用 xy 近似接触半径：

```python
def contact_radius_xy(obj):
    if obj.object_type == "sphere":
        return obj.radius
    if obj.object_type == "cube":
        return max(obj.size[0], obj.size[1]) / 2
    if obj.object_type == "cylinder":
        return obj.radius
```

## 4. State 怎么记录

### 4.1 FrameState

每帧保存所有物体状态。建议 `states.npz` 中保存数组，不要把逐帧状态塞进 metadata JSON。

```python
object_ids:              [num_objects]
is_static:               [num_objects]
positions:               [num_frames, num_objects, 3]
quaternions_wxyz:        [num_frames, num_objects, 4]
linear_velocities:       [num_frames, num_objects, 3]
angular_velocities:      [num_frames, num_objects, 3]
visible_area:            [num_frames, num_views, num_objects]
in_view:                 [num_frames, num_views, num_objects]
contact_matrix:          [num_frames, num_objects, num_objects]
dynamic_static_contact:  [num_frames, num_objects]
```

### 4.2 为什么逐帧状态必要

逐帧状态用于计算：

- `first_contact_time`
- `stop_time`
- `travel_distance`
- `rebound_height`
- `closest_approach_time`
- `scattering_angle`
- `visible_area_by_view`
- `left_visible_area`

如果只保存最后标签，后续发现标签算法错了，就无法重算。

## 5. Contact 怎么记录

### 5.1 RawContact

物理引擎每个 substep 的接触先保存成 raw contact：

```python
@dataclass
class RawContact:
    time: float
    frame: int
    substep: int
    object_a: str
    object_b: str
    position: tuple[float, float, float]
    normal_on_b: tuple[float, float, float]
    normal_force: float | None
    distance: float | None
```

Raw contact 可以很多，metadata 不一定全存。建议：

- `states.npz` 或 `contacts.parquet` 保存完整 raw contacts。
- `metadata.json` 只存提炼后的重要事件。

接触计数不要简单累计所有 substep contact 点。球放在地面上的 resting contact 会持续存在，若逐 substep 累计会让 `dynamic_static` 变成几十到几百，缺乏区分度。

推荐同时记录：

```json
"contact_counts": {
  "dynamic_dynamic_new": 1,
  "dynamic_static_new": 2,
  "dynamic_static_resting_frames": 72,
  "total_new": 3
}
```

其中：

- `*_new`：接触 pair 从“上一帧无接触”变成“当前帧有接触”的次数。
- `*_resting_frames`：持续接触的帧数，主要用于地面 resting contact 质检。
- `total_new`：所有新接触事件数，不重复累计持续接触。

### 5.2 接触对象分类

```python
def contact_kind(a, b):
    if not a.static and not b.static:
        return "dynamic_dynamic_contact"
    if a.static != b.static:
        return "dynamic_static_contact"
    return "static_static_contact"
```

通常忽略 `static_static_contact`。

### 5.3 first contact 提取

```python
def first_contact(raw_contacts, pair=None, kind=None):
    for c in sorted(raw_contacts, key=lambda x: (x.frame, x.substep)):
        if pair is not None and set([c.object_a, c.object_b]) != set(pair):
            continue
        if kind is not None and contact_kind_by_ids(c.object_a, c.object_b) != kind:
            continue
        return c
    return None
```

### 5.4 contact_pair_sequence

S7 必须记录完整序列。推荐压缩连续重复接触：

```python
def contact_pair_sequence(raw_contacts):
    seq = []
    last_pair = None
    for c in sorted(raw_contacts, key=lambda x: (x.frame, x.substep)):
        pair = tuple(sorted([c.object_a, c.object_b]))
        if pair != last_pair:
            seq.append({
                "pair": list(pair),
                "time": c.time,
                "frame": c.frame
            })
            last_pair = pair
    return seq
```

示例：

```json
[
  {"pair": ["object_a", "object_b"], "time": 0.42, "frame": 5},
  {"pair": ["object_b", "object_c"], "time": 0.75, "frame": 9},
  {"pair": ["object_c", "right_wall"], "time": 1.22, "frame": 15}
]
```

## 7. 常用事件计算方法

### 7.1 stop

```python
def detect_stop(states, object_id, v_eps=0.03, w_eps=0.05, hold_frames=3):
    speed = norm(linear_velocities[:, obj_idx, :])
    angular = norm(angular_velocities[:, obj_idx, :])
    stopped = (speed < v_eps) & (angular < w_eps)
    return first_frame_holding(stopped, hold_frames)
```

记录：

```json
{
  "event_type": "stop",
  "objects": ["object"],
  "frame": 18,
  "time": 1.5,
  "metrics": {
    "linear_speed": 0.018,
    "angular_speed": 0.031,
    "hold_frames": 3
  }
}
```

### 7.2 slide_start

用于 S3 斜面临界静止：

```python
def detect_slide_start(states, object_id, initial_pos, pos_eps=0.01, v_eps=0.03):
    displacement = norm(positions[:, obj_idx, :] - initial_pos)
    speed = norm(linear_velocities[:, obj_idx, :])
    moving = (displacement > pos_eps) | (speed > v_eps)
    return first_true(moving)
```

### 7.3 rolling_transition

球向 +x 运动时，纯滚动近似满足：

```text
v ≈ radius * |omega_tangent|
```

通用做法：

```python
def rolling_error(v, omega, radius, tangent_axis):
    v_t = dot(v, tangent_axis)
    omega_expected = abs(v_t) / radius
    omega_actual = norm(omega)
    return abs(omega_actual - omega_expected)
```

当连续若干帧 `rolling_error < threshold`，记录 `rolling_transition`。

### 7.4 rebound_peak

用于 S1：

```python
def rebound_peak_after_contact(states, object_id, first_contact_frame):
    z = positions[:, obj_idx, 2]
    search = z[first_contact_frame:]
    peak_local = argmax(search)
    return first_contact_frame + peak_local
```

### 7.5 closest_approach

用于 S8 负样本：

```python
def closest_approach(states, obj_i, obj_j, contact_radius_i, contact_radius_j):
    d = norm(positions[:, i, :] - positions[:, j, :], axis=1)
    clearance = d - (contact_radius_i + contact_radius_j)
    frame = argmin(clearance)
    return frame, clearance[frame]
```

### 7.6 leave_visible_area

用 segmentation mask 最稳：

```python
visible_area[frame, view, object] = pixel_count(mask == object_id)
left_visible_area = visible_area drops to 0 after being visible
```

如果没有 segmentation，退化为投影 bbox：

```python
bbox = project_aabb_to_image(aabb, camera)
visible = bbox intersects image_bounds
```

保存策略：

- debug split、invalid 样本、低可见性样本、stress 样本建议保存 segmentation。
- 主训练全量样本可以只保存投影 bbox 计算出的 `visible_area_by_view`，不强制保存 mask 文件。
- depth 只在遮挡/墙/障碍/质检抽样中强制保存；普通样本可写 `depth_path=null`。

## 8. Derived labels 怎么计算

### 8.1 effective_restitution

定义：碰后法向分离速度 / 碰前法向接近速度。

```python
def effective_restitution(v_a_pre, v_b_pre, v_a_post, v_b_post, normal):
    rel_pre = dot(v_a_pre - v_b_pre, normal)
    rel_post = dot(v_b_post - v_a_post, normal)
    if abs(rel_pre) < 1e-6:
        return None
    return max(0.0, rel_post / abs(rel_pre))
```

注意：

- 墙面碰撞时，墙速度为 0。
- 地面反弹时，法线通常是 `[0,0,1]`。
- 斜面接触时，法线用 `ramp_normal`。
- `effective_restitution` 应优先使用引擎 substep 级接触前后速度计算。12fps 帧间隔约 83ms，直接取 `first_contact.frame - 1` 和 `first_contact.frame + 1` 可能已经错过碰撞瞬间，尤其高速碰撞会低估或高估恢复系数。
- 如果没有 substep state，只能把帧级速度计算结果标记为近似值：`effective_restitution_source="frame_approx"`；有 substep state 时写 `effective_restitution_source="substep_contact_state"`。

### 8.2 normal / tangential speed

```python
v_normal = dot(v, normal) * normal
v_tangent = v - v_normal
normal_speed = norm(v_normal)
tangential_speed = norm(v_tangent)
```

### 8.3 scattering_angle

二维平面中：

```python
angle = atan2(v_after_y, v_after_x) - atan2(v_before_y, v_before_x)
```

输出单位建议 rad；如果需要可额外记录 degree。

### 8.4 momentum / kinetic energy

```python
momentum = sum(m_i * v_i)
kinetic_energy = sum(0.5 * m_i * dot(v_i, v_i))
```

如果要记录转动能，需要有转动惯量；目前可先记录平动动能。

```python
first_wall = first_contact(raw_contacts, pair=("object", "wall"))
```

### 12.4 velocity decomposition

```python
v_pre = velocity_before(first_wall, "object")
v_post = velocity_after(first_wall, "object")
incident_speed_normal = abs(dot(v_pre, wall_normal))
reflected_speed_normal = abs(dot(v_post, wall_normal))
tangential_speed_before = norm(v_pre - dot(v_pre, wall_normal) * wall_normal)
tangential_speed_after = norm(v_post - dot(v_post, wall_normal) * wall_normal)
```

### 12.5 labels

必须记录：

```text

post_collision_velocity
incident_speed_normal
reflected_speed_normal
tangential_speed_before/after
effective_restitution
rebound_distance
```

### 13.2 hit / miss 预筛

二维轨迹最近距离：

```python
d_min = abs(-(x_b - x_a) * sin(angle) + (y_b - y_a) * cos(angle))
will_hit = d_min < radius_a + radius_b
```

```python
if scene_type in ["S5_球撞球", "S6_球撞方块"]:
```

```python
def make_metadata(
```

## 19. 写脚本时的强制约定

1. 所有时间字段同时写 `time` 和 `frame`。
2. 所有速度字段保留向量，不只写 speed。
3. 所有 contact 事件写对象 pair、normal、position。
4. S7 必须写完整 `contact_pair_sequence`。
5. S8 必须写 `negative_reason` 和 `total_dynamic_dynamic_contact_count`。
6. 出界不是错误，但必须写 `left_visible_area` 和可见帧数。
7. `sampled_params` 和 `derived_labels` 必须分开。
8. `valid_sample=false` 的 metadata 也建议保留到 invalid 目录。
9. metadata 里路径一律相对数据集根目录。
10. quaternion 对外统一 `[w,x,y,z]`，即使引擎内部不是这个顺序。
