## 三、池内取值物理合理性分析

### 3.1 restitution = 0 的广泛使用

8 个场景中，restitution=0 出现在以下位置：

| 位置 | 场景 | 判定 |
|---|---|---|
| S1 L1/2/4/5/6 | 地面+物体=0，自由落体 | **合理**：隔离落地时间，无反弹干扰 |
| S2 全部 | 物体=0，水平滑动 | **合理**：滑动场景无需反弹 |
| S3 全部 | 地面/斜面/物体=0，斜面滑动 | **合理**：斜面滑动无需反弹 |
| S4 通用固定项 | 地面=0，墙面碰撞 | **合理**：地面仅作支撑，反弹由墙面决定 |
| S5/S6 通用固定项 | 地面=0，碰撞隔离 | **合理**：隔离碰撞物理 |
| S5 L1 | sphere_b restitution 含 0 | **边缘**：两球完全非弹性碰撞 → 粘在一起。物理上可行但视觉不自然 |
| S6 L1 | cube_b restitution 含 0 | **同上** |
| S7 L1 | object_b/c restitution 含 0 | **同上**，三体链中 BC 碰撞无分离 |

**建议**：S5/S6/S7 的 restitution=0 极值作为数据集的边界样本保留，但比例应控制在 ~10% 以内。

### 3.2 S1 L4：restitution=0 + lateralFriction=0.5 组合

水平抛体子任务中，物体以 vx≠0 落地后：
- 无反弹（restitution=0）→ 垂直运动立即停止
- 摩擦 0.5 → 水平滑行距离 = v²/(2μg)，v=0.6 时约 3.7cm ≈ 1.5px

**问题**：水平运动几乎不可见。但水平抛体验证的是"落地时间仅由 z 决定"，落地后行为无关。**设计可接受**。

### 3.3 S2 L1：lateralFriction=1.0 的可见性

- μ=1.0, v0=2.0m/s → 停止时间 = 2/(1×9.8) = 0.20s ≈ 2.4 帧
- 停止过程被压缩到 2-3 帧内

**问题**：约束已注明"避免停止过程压缩到 1-2 帧"，但 μ=1.0 时 2.4 帧仍很临界。与 μ=0.8（3.1 帧）区分度很低。**建议**：将上限改为 0.75 或 0.8，或加帧率说明。

### 3.4 S3 L1：3 个静态斜面角度冗余

- incline = [0.08, 0.12, 0.15, 0.26, 0.35, 0.52]
- 摩擦 μ=0.2，临界角 θc = arctan(0.2) = 0.197 rad
- 前 3 个角度（0.08, 0.12, 0.15）均 < 0.197 → 全部静止

**问题**：3 个静态角度产生完全相同的视觉效果（物体不动），样本冗余。**建议**：保留 1 个静态角度（如 0.12 或 0.15），增加一个近临界滑动角度（如 0.22）。

### 3.5 S5/S6：对心碰撞设计

S5 L1/L2/L3/L4、S6 L1/L2/L3/L4 均使用相同 y 坐标（对心碰撞）：
- sphere_a 的 y = sphere_b/cube_b 的 y → 对心
- 碰撞后运动沿 x 轴一维方向

**合理**：先学一维碰撞规律，再在 L5+ 引入斜碰。渐进式设计正确。

### 3.6 S7 L5：restitution=0.5 的物理学精妙设计

三体链式碰撞中，L5 刻意将三物体 restitution 固定为 0.5：
- AB 碰撞：A 减速但不停止，B 加速
- BC 碰撞：B 减速但不停止，C 加速
- 结果：A(0.45) > B(0.34) → A 可追赶 B → 二次碰撞

用 e=0.5 而非 e=0.8/1.0 的原因是：e 越接近 1，A 在碰撞后速度越接近 0，无法产生二次碰撞。**物理上非常精妙** ✓

### 3.7 碰撞质量比覆盖

| 文件 | 质量取值 | 比率 | 覆盖 |
|---|---|---|---|
| S5 L3 | [0.3, 0.5, 1.0, 2.0, 5.0] vs 1.0 | 0.3~5.0 | 轻→重、等质量、重→轻 |
| S6 L3 | 同上 | 同上 | 同上 |
| S7 L3 | [0.7,1.0,1.6], [1.0,2.5,1.0], [1.0,0.4,1.0], [1.6,1.0,0.7] | 多种序列 | 增/减/中重/中轻 |

**合理**：质量比覆盖了动量传递的关键区间。✓

### 3.8 自旋角速度 8 rad/s 的选择

S4 L8, S5 L8, S6 L9, S7 L9 统一使用 spin = [0, ±8] rad/s：
- 半径 0.22m → 表面线速度 = 8×0.22 = 1.76 m/s
- 入射速度 ~2.0-2.2 m/s → 表面速度与平移速度同量级
- 3s 内旋转约 3.8 圈 → 视觉可分辨

**合理**：spin 量级与平动匹配，效应可见。✓

### 3.9 S2 L6：near_rolling 条件

ω_near_rolling = -vx/r。vx=2.0, r=0.22 → ω = -9.09 rad/s
纯滑动 ω=0 → 与 near_rolling 差异 9.09 rad/s

**合理**：两种初始条件的角速度差异足够大，滑动→滚动转换过程清晰可见。✓

### 3.10 S8 L10：radius=0.05 不可见

64×64 分辨率，1px ≈ 0.078m：
- r=0.05 → 直径 = 1.3px → **肉眼不可见**
- r=0.08 → 直径 = 2.1px → 勉强可见

配置文件已备注"视觉信号很弱"。**建议**：评估此 Level 是否需要保留。若保留，对应的视频应标注为"物理标签可用但视觉不可见"。

### 3.11 lateralFriction ∈ [1.5, 2.0, 3] 的极端值

S8 L6 使用了池内极端值 [1.5, 2.0]，参数详解池上限为 3：
- μ=2.0: v0=1.0 → 停止时间 = 1/(2×9.8) = 0.051s < 1 帧 → 瞬间停止
- μ=3.0: 几乎"粘住"

**合理**：作为地面摩擦停止运动的极端样本，满足"碰撞前因摩擦停止"的学习目标。但 μ=2.0 的停止过程几乎不可见（< 1 帧），建议 μ 上限取 1.5。

### 3.12 S3 ramp rollingFriction=0.01 与 0 的区分度

- rollingFriction=0.01: 球在斜面上滚动减速，3s 内角速度变化约 3.4 rad/s（从 9 降至 ~5.6）
- rollingFriction=0: 球以恒定角速度滚动

**区分度足够**。但 rollingFriction=0.01 不在池内，最近池值为 0.01——等等，0.01 在池内。rollingFriction 池 = [0, 0.001, 0.005, 0.007, 0.01, 0.05, 0.1, ...]。0.01 在池内 ✓。但 S2 L6/S3 用的 0.03 不在池内。
