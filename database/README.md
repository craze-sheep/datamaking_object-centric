# 物理仿真视频数据集说明

本目录保存一个基于 Kubric + Blender + PyBullet 生成的物理仿真视频数据集，面向物理推理、物体交互建模、碰撞/非碰撞判别、多视角视觉理解等研究任务。

每个样本是一个单视角视频样本。同一个物理配置会按多个相机视角展开为多个 `sample_id` 目录，因此本文中的“样本数”默认指视角展开后的单视角视频样本数。每个样本包含渲染视频、深度图、逐帧 RGB 图像、逐帧逐物体分割 mask、物体静态属性、物理动态状态 JSON 和物体间力矩阵。

## 全局参数

| 参数 | 值 | 说明 |
|---|---:|---|
| 分辨率 | `128 x 128` | RGB、深度和分割 mask 的空间分辨率 |
| 帧数 | `36` 帧/样本 | 帧目录通常为 `dynamic/1` 到 `dynamic/36` |
| FPS | `12` | 视频帧率 |
| 时长 | `3.0 s` | 每个样本 3 秒 |
| 重力 | `[0, 0, -9.8]` | 单位 `m/s^2` |
| 长度单位 | `m` | 位置、尺寸、深度 |
| 质量单位 | `kg` | 物体质量 |
| 线速度单位 | `m/s` | `velocity` |
| 角速度单位 | `rad/s` | `angular_velocity` |
| 角度单位 | `rad` | 斜面角、旋转角等 |
| 力单位 | `N` | 等价于 `kg*m/s^2` |

当前数据集规模约 3.2 万个单视角视频样本。`database/checkout/validation_report_s1_s8.txt` 中的当前完整校验统计为 `32,080` 个视角样本；设计目标口径约为 `31,880` 个样本，具体以当前目录和校验报告为准。

## 目录结构

```text
database/
  S{scene}/
    L{level}/
      {sample_id}/
        {sample_id}.mp4
        {sample_id}.npz
        video.json
        object_static.json
        dynamic/
          {frame_num}/
            {frame_num}.png
            force_matrix.json
            object_dynamicjson/
              {object_id}.json
            object_segment/
              {object_id}.npz
  checkout/
    validate_s1_s8.py
    validation_report_s1_s8.txt
```

### 顶层组织

- `S{scene}`：场景大类，当前为 `S1` 到 `S8`。
- `L{level}`：场景下的物理变量或研究子任务。
- `{sample_id}`：单视角样本目录。多视角场景中，同一组物理参数会生成多个不同视角的样本目录。
- `checkout/`：随数据目录放置的数据校验工具和校验报告，用于检查完整性、JSON 结构、深度、分割、力矩阵和视角分布。

### 单样本文件

- `{sample_id}.mp4`：Blender/Kubric 渲染得到的 RGB 视频。
- `{sample_id}.npz`：深度图文件，包含 `depth`，形状为 `(36, 128, 128)`，类型为 `float32`，单位为米。
- `video.json`：视频级元数据，包括帧率、时长、重力、单位、相机参数、视角名、文件路径和任务变量。
- `object_static.json`：该样本中所有物体的静态属性列表，包括地面、墙、斜面、障碍物和动态物体。
- `dynamic/{frame_num}/{frame_num}.png`：该帧 RGB 图像。
- `dynamic/{frame_num}/force_matrix.json`：该帧物体间接触力矩阵。
- `dynamic/{frame_num}/object_dynamicjson/{object_id}.json`：该帧该物体的动态状态。
- `dynamic/{frame_num}/object_segment/{object_id}.npz`：该帧该物体的二值分割 mask。

## S1: 自由落体与抛体运动

`S1` 研究竖直方向运动规律，包括自由落体、竖直初速度、反弹、水平运动独立性、质量无关性、尺寸无关性和形状泛化。

- 视角：`front`, `top`，共 2 个视角。
- 物体：`ground` + 1 个动态物体，动态物体为 `sphere` 或 `cube`。
- 地面尺寸：约 `8 x 6`。
- 典型推理目标：根据高度、速度、恢复系数、质量、尺寸或形状变化预测落地时间、轨迹和反弹高度。

| Level | 物理变量 / 子任务 | 样本数 |
|---|---|---:|
| `L1` | 自由落体高度 -> 落地时间。改变初始高度，考察下落时间与高度的关系。 | `100 x 2 = 200` |
| `L2` | 竖直初速度 -> 运动轨迹。给物体向上或向下的初速度，考察竖直方向轨迹。 | `100 x 2 = 200` |
| `L3` | 弹跳恢复系数 -> 反弹高度。改变物体或接触面的 `restitution`，观察首次碰撞后的反弹幅度。 | `100 x 2 = 200` |
| `L4` | 水平位置/速度独立性。改变 `x/y` 初始位置或水平速度，验证其不影响竖直自由落体规律。 | `100 x 2 = 200` |
| `L5` | 质量无关性。改变质量，验证理想重力场中质量不影响自由落体时间。 | `100 x 2 = 200` |
| `L6` | 尺寸无关性。改变球半径或物体尺寸，考察几何尺寸对接触时刻和视觉表现的影响。 | `150 x 2 = 300` |
| `L7` | 形状泛化。比较 `sphere` 与 `cube` 在相同初始条件下的行为。 | `150 x 2 = 300` |

- 典型推理目标：由摩擦、初速度、质量、尺寸、方向和形状预测减速、停止时间和停止距离。

| `L2` | 初速度大小 -> 停止距离。改变初始线速度模长，观察滑行距离。 | `80 x 3 = 240` |
| `L3` | 质量无关性。改变质量，验证库仑摩擦模型下滑动减速度对质量的独立性。 | `80 x 3 = 240` |
| `L4` | 尺寸/接触面积无关性。改变物体尺寸或接触面积，考察理想摩擦模型中的停止规律。 | `80 x 3 = 240` |
| `L5` | 初速度方向与二维滑动。改变水平面内速度方向，研究二维轨迹和停止点。 | `120 x 3 = 360` |
| `L6` | 球体滑动与滚动转换。研究球体从纯滑动到滚动的速度和角速度变化。 | `120 x 3 = 360` |

## S3: 斜面运动

## S8: 未碰撞负样本

`S8` 是 negative samples 场景，目标是构造“看起来可能交互但动态物体之间没有直接接触”的样本，用于训练和评估模型区分“碰撞”和“未碰撞”。

- 视角：`front`, `back`, `left`, `right`, `top`，共 5 个视角。
- 物体：`ground` + 2-9 个动态物体，可能包含 `wall` 或 `obstacle`。
- 特点：所有动态物体之间无直接接触；部分样本可能有静态障碍物、边界、摩擦或外力干预。
- 典型推理目标：识别空间错开、时间错开、速度不足、障碍阻隔、高度错开、边界反弹、擦肩而过等非碰撞原因。

| Level | 物理变量 / 子任务 | 样本数 |
|---|---|---:|
| `L1` | 空间分离。平行轨迹或近似平行轨迹错开，物体始终不相交。 | `120 x 5 = 600` |
| `L2` | 时间分离。物体先后经过同一区域，但到达时间错开。 | `120 x 5 = 600` |
| `L3` | 速度差异。追赶物体追不上，或目标物体已提前越过可能接触点。 | `120 x 5 = 600` |
| `L4` | 随机参数全空间过滤。随机采样初始状态，并通过物理仿真过滤掉发生动态接触的样本。 | `120 x 5 = 600` |
| `L5` | 静态障碍物阻隔。障碍物或墙体阻断动态物体之间的直接接触。 | `120 x 5 = 600` |
| `L6` | 摩擦力使物体停止。物体因地面摩擦提前停止，未到达碰撞区域。 | `120 x 5 = 600` |
| `L7` | 三维高度错开。平面投影接近，但高度不同导致不接触。 | `120 x 5 = 600` |
| `L8` | 被其他运动物体阻挡但未直接碰撞。中间物体或运动路径改变使目标物体错过。 | `120 x 5 = 600` |
| `L9` | 反弹边界内反复运动但总错过。边界反弹制造复杂轨迹，但动态物体之间仍无接触。 | `120 x 5 = 600` |
| `L10` | 极小尺寸/擦肩而过。物体间距离接近，但由于尺寸小或间隙足够而没有碰撞。 | `120 x 5 = 600` |
| `L11` | 旋转导致接触面错开。姿态或旋转改变潜在接触面，使物体擦过。 | `120 x 5 = 600` |
| `L12` | 力干预使物体转向。外力或轨迹干预使物体偏离原本可能碰撞的路径。 | `120 x 5 = 600` |
| `L13` | 完全静止多物体。多个物体保持静止，作为无碰撞静态负样本。 | `120 x 5 = 600` |
| `L14` | 速度方向严格背离。初始速度方向相互远离，动态物体之间不会接触。 | `120 x 5 = 600` |

## 数据格式说明

### `video.json`

路径：

```text
database/S{scene}/L{level}/{sample_id}/video.json
```

主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `duration_s` | number | 视频时长，当前为 `3.0` 秒 |
| `fps` | number | 帧率，当前为 `12` |
| `num_frames` | number | 帧数，当前为 `36` |
| `gravity` | array[3] | 重力向量，当前为 `[0.0, 0.0, -9.8]` |
| `units` | object | 单位说明，如长度 `m`、质量 `kg`、力 `kg*m/s^2` |
| `cameras` | array | 相机列表；当前每个样本通常包含 1 个视角相机 |
| `physics_hz` | number | 物理仿真频率，常见为 `240` |
| `level_name` | string | level 的程序化名称 |
| `subtask` | string | 该 level 的推理子任务 |
| `main_variable` | string | 该样本主要变化的物理变量 |

`cameras[0]` 主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `view_name` | string | 视角名，如 `front/top/left/back/right` |
| `type` | string | 相机类型，如 `Perspective` 或 `Orthographic` |
| `position` | array[3] | 相机位置，单位为米 |
| `look_at` | array[3] | 相机朝向目标点，单位为米 |
| `focal_length` | number/null | 透视相机焦距 |
| `sensor_width` | number/null | 传感器宽度 |
| `orthographic_scale` | number/null | 正交相机尺度；透视相机样本中可能不存在 |
| `resolution` | array[2] | 图像分辨率，当前为 `[128, 128]` |
| `video_path` | string | 相对样本目录的视频文件路径 |
| `depth_path` | string | 相对样本目录的深度文件路径 |

### `{sample_id}.npz`

路径：

```text
database/S{scene}/L{level}/{sample_id}/{sample_id}.npz
```

主要数组：

| 键 | 类型/形状 | 说明 |
|---|---|---|
| `depth` | `float32`, `(36, 128, 128)` | 深度图，单位为米 |
| `unit` | string | 深度单位，当前为 `m` |

读取含义：

```text
depth[frame_index, y, x]
```

其中 `frame_index` 从 `0` 到 `35`，对应帧目录 `1` 到 `36`。

### `object_static.json`

路径：

```text
database/S{scene}/L{level}/{sample_id}/object_static.json
```

顶层是数组，每个元素描述一个物体的静态属性。地面、墙、斜面、障碍物和动态物体都会出现在该数组中。

| 字段 | 类型 | 说明 |
|---|---|---|
| `object_id` | int | 物体编号；当前脚本中常用正整数 |
| `segmentation_id` | int | 渲染分割中的实例编号 |
| `object_type` | string | `ground/sphere/cube/cylinder/ramp/wall/obstacle` 等 |
| `static` | bool | 是否静态；地面、墙、斜面、障碍物通常为 `true` |
| `mass` | number/null | 质量，单位 `kg`；静态物体可能为 `null` |
| `radius` | number/null | 球或圆柱半径，单位 `m` |
| `height` | number/null | 圆柱高度或相关几何高度，单位 `m` |
| `size` | array/null | 方块、地面、墙、斜面等尺寸，单位 `m` |
| `lateralFriction` | number | 滑动摩擦系数 |
| `rollingFriction` | number | 滚动摩擦系数 |
| `spinningFriction` | number | 自旋摩擦系数 |
| `restitution` | number | 碰撞恢复系数 |
| `color_name` | string | 颜色名称 |
| `rgba` | array[4] | RGBA 颜色值 |

### `object_dynamicjson/{object_id}.json`

路径：

```text
database/S{scene}/L{level}/{sample_id}/dynamic/{frame_num}/object_dynamicjson/{object_id}.json
```

每一帧、每个物体都会写一个动态 JSON。静态物体也会记录动态 JSON，只是位置和速度通常不变。

| 字段 | 类型 | 说明 |
|---|---|---|
| `object_id` | int | 物体编号，与 `object_static.json` 对应 |
| `time` | number | 当前帧时间，单位秒；通常为 `(frame_num - 1) / fps` |
| `visible_area` | int | 当前视角下该物体可见像素数 |
| `position` | array[3] | 世界坐标位置，单位 `m` |
| `quaternion` | array[4] | 姿态四元数，Kubric 格式 `[w, x, y, z]` |
| `velocity` | array[3] | 线速度，单位 `m/s` |
| `angular_velocity` | array[3] | 角速度，单位 `rad/s` |
| `resultant force` | array[3] | 该帧合力，单位 `N`；注意当前实际键名含空格 |
| `segmentation_path` | string | 相对动态 JSON 所在目录的分割 mask 路径 |

说明：

- `frame_num` 从 `1` 开始。
- `time=0.0` 对应 `dynamic/1`。
- `dynamic/36` 对应时间约 `2.916667 s`。
- 动态物体的合力通常包含重力和接触力；静态物体合力通常为 `[0, 0, 0]`。

### `object_segment/{object_id}.npz`

路径：

```text
database/S{scene}/L{level}/{sample_id}/dynamic/{frame_num}/object_segment/{object_id}.npz
```

主要数组：

| 键 | 类型/形状 | 说明 |
|---|---|---|
| `mask` | `uint8`, `(128, 128)` | 二值分割 mask，值为 `0` 或 `1` |
| `object_id` | int | 物体编号 |
| `segmentation_id` | int | 实例分割编号 |
| `frame_num` | int | 帧号，当前为 `1` 到 `36` |

`mask[y, x] = 1` 表示该像素属于当前物体。若物体在该视角或该帧完全不可见，`mask` 可能全 0；这通常与遮挡、出画或几何视角有关。

### `force_matrix.json`

路径：

```text
database/S{scene}/L{level}/{sample_id}/dynamic/{frame_num}/force_matrix.json
```

主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `object_order` | array[int] | 当前样本中的物体编号列表 |
| `force_matrix` | array | 物体间接触力矩阵，当前文件通常保存为固定 `10 x 10` 槽位矩阵 |

如果按 `object_order` 将固定槽位矩阵压缩为 `N x N`，概念上的矩阵元素含义为：

```text
force_matrix[i][j] = object_order[j] 作用在 object_order[i] 上的力
```

当前实现中矩阵以固定 `10 x 10` 槽位保存，行列槽位通常直接对应 `object_id`；`object_order` 给出当前样本中的有效物体编号。若下游任务需要压缩矩阵，可先按 `object_order` 取出有效行列，再得到按物体列表对齐的 `N x N` 矩阵。

未使用槽位为 `null`；有效物体对应的元素为三维力向量 `[fx, fy, fz]` 或 `null`。

- `[fx, fy, fz]`：接触力向量，单位 `N`。
- `[0.0, 0.0, 0.0]`：对应槽位有物体，但两者之间无接触力或自作用力为 0。
- `null`：该矩阵槽位未对应有效物体，或没有可记录的力。
- 对角线通常为 `[0.0, 0.0, 0.0]`。
- 理想情况下，相互作用力近似满足 `force_matrix[i][j] = -force_matrix[j][i]`，但数值平均和接触求解可能带来小误差。

## 读取建议

1. 读取 `video.json` 获取 `fps`、`num_frames`、`view_name`、`video_path` 和 `depth_path`。
2. 读取 `object_static.json` 建立 `object_id -> object_type/static/geometry/material` 映射。
3. 对每一帧遍历 `dynamic/{frame_num}/object_dynamicjson/`，读取物体状态。
4. 对需要视觉监督的物体，读取 `object_segment/{object_id}.npz` 中的 `mask`。
5. 对需要物理交互监督的任务，读取 `force_matrix.json` 并结合 `object_order` 解释物体间作用力。
6. 多视角分析时，按 `video.json` 中的 `cameras[0].view_name` 将不同 `sample_id` 归并到同一物理配置口径。

## 校验信息

`checkout/` 是本数据集随附的校验目录，包含校验脚本和最近一次校验报告。

数据校验脚本位于：

```text
database/checkout/validate_s1_s8.py
```

校验报告位于：

```text
database/checkout/validation_report_s1_s8.txt
```

推荐在 `checkout/` 目录下运行校验，这样新报告会写回同目录：

```bash
cd /home/lzy/project/slot-datamaking/database/checkout
python validate_s1_s8.py
```

校验覆盖内容包括：

- `S1` 到 `S8` 的 level 是否完整。
- 每个 level 的样本数是否达到预期。
- 顶层文件是否存在：`.mp4`、`.npz`、`video.json`、`object_static.json`。
- 每个样本是否包含 36 帧。
- 每帧是否包含 RGB、动态 JSON、分割 mask 和力矩阵。
- `video.json` 中的帧率、时长、重力、视角和相机信息是否符合预期。
- `object_static.json`、`object_dynamicjson`、`object_segment` 和 `force_matrix` 的结构是否可解析。
