# Kubric 官方 Docker 使用方法

只使用官方推荐的 Docker 方式。不要在宿主机手动配 Blender、`bpy`、Python 依赖；官方镜像 `kubricdockerhub/kubruntu` 已经包含 Kubric、Blender、PyBullet 和渲染所需依赖。

官方链接：

- GitHub: https://github.com/google-research/kubric
- 文档: https://kubric.readthedocs.io
- Docker 镜像: https://hub.docker.com/r/kubricdockerhub/kubruntu

---

## 1. Docker 自动启动

当前环境是 WSL2，已配置 WSL 启动时自动拉起 Docker daemon。

启动脚本：

```bash
/usr/local/sbin/wsl-startup.sh
```

WSL 配置：

```text
/etc/wsl.conf
```

核心配置：

```text
[boot]
command=/usr/local/sbin/wsl-startup.sh
```

如果刚打开 WSL 后想确认 Docker 是否已经可用，运行：

```bash
docker info
```

看到 `Server:` 部分就说明 Docker 可用。

如果没有看到 `Server:`，可以手动执行一次：

```bash
sudo /usr/local/sbin/wsl-startup.sh
```

## 2. 获取官方 Kubric 镜像

```bash
docker pull kubricdockerhub/kubruntu
```

如果网络访问 Docker Hub 超时，但本机已有镜像，也可以直接使用本地缓存：

```bash
docker images kubricdockerhub/kubruntu
```

本机已验证存在：

```text
kubricdockerhub/kubruntu:latest
```

---

## 3. 运行官方 Hello World

进入 Kubric 源码目录：

```bash
cd /home/lzy/project/slot-datamaking/kubric-main
```

按官方方式运行：

```bash
docker run --rm --interactive \
  --user $(id -u):$(id -g) \
  --volume "$(pwd):/kubric" \
  kubricdockerhub/kubruntu \
  /usr/bin/python3 examples/helloworld.py
```

参数说明：

- `--rm`: 容器结束后自动删除容器。
- `--interactive`: 保持标准输入可用。
- `--user $(id -u):$(id -g)`: 让输出文件属于当前用户。
- `--volume "$(pwd):/kubric"`: 把当前 Kubric 源码目录挂载到容器内 `/kubric`。
- `kubricdockerhub/kubruntu`: 官方 Kubric 镜像。
- `/usr/bin/python3 examples/helloworld.py`: 在容器里运行官方示例。

## 4. 验证 Blender 和输出

`examples/helloworld.py` 会在 Docker 容器里调用官方镜像内置的 Blender 渲染。

成功后检查：

```bash
ls -l output/helloworld.blend \
      output/helloworld.png \
      output/helloworld_segmentation.png \
      output/helloworld_depth.png
```

本机测试已成功生成：

```text
output/helloworld.blend
output/helloworld.png
output/helloworld_segmentation.png
output/helloworld_depth.png
```

输出含义：

- `helloworld.blend`: Blender 场景文件。
- `helloworld.png`: RGB/RGBA 渲染图。
- `helloworld_segmentation.png`: 实例分割图。
- `helloworld_depth.png`: 深度图。

## 6. 最小 Kubric 脚本流程

官方示例的核心流程是：

```text
创建 Scene
-> 添加物体、灯光、相机
-> 可选：PyBullet 仿真
-> Blender 渲染
-> 保存 RGB / segmentation / depth / .blend
```

Hello World 对应代码结构：

```python
import kubric as kb
from kubric.renderer.blender import Blender as KubricRenderer

scene = kb.Scene(resolution=(256, 256))
renderer = KubricRenderer(scene)

scene += kb.Cube(name="floor", scale=(10, 10, 0.1), position=(0, 0, -0.1))
scene += kb.Sphere(name="ball", scale=1, position=(0, 0, 1.))
scene += kb.DirectionalLight(name="sun", position=(-1, -0.5, 3),
                             look_at=(0, 0, 0), intensity=1.5)
scene += kb.PerspectiveCamera(name="camera", position=(3, -1, 4),
                              look_at=(0, 0, 1))

renderer.save_state("output/helloworld.blend")
frame = renderer.render_still()

kb.write_png(frame["rgba"], "output/helloworld.png")
kb.write_palette_png(frame["segmentation"], "output/helloworld_segmentation.png")
kb.write_scaled_png(frame["depth"], "output/helloworld_depth.png")
```

## 7. 后续运行自己的脚本

把自己的脚本放在 `kubric-main` 目录下，仍然用官方镜像运行：

```bash
cd /home/lzy/project/slot-datamaking/kubric-main

docker run --rm --interactive \
  --user $(id -u):$(id -g) \
  --volume "$(pwd):/kubric" \
  kubricdockerhub/kubruntu \
  /usr/bin/python3 your_script.py
```

如果脚本在项目其他目录，可以额外挂载项目根目录；但最简单的官方用法是把 worker/script 放在 Kubric 仓库目录内运行。
