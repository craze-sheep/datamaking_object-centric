# 致命错误 5：S8 多个 level 参数间距不足导致物体系统性碰撞

## 问题描述

S8（泛化样本）的核心约束是 `no_dynamic_collision`——物体之间不能发生动态碰撞。脚本生成候选样本后运行物理仿真，如果 `dynamic_dynamic_contact_count > 0` 则过滤掉该候选。

**L2 率先暴露**：1200 个候选全部被过滤（`dynamic_dynamic_contact_count=1`），脚本报错退出。根因是 `distance = 1.8 + i * 0.35 * speed`，时间间隔仅 0.35s，物体到达原点时必然碰撞。

**排查发现 L2 不是唯一问题**：经 Codex 对所有 level 做几何分析 + PyBullet 碰撞扫描，发现 L3、L5、L7、L10、L11、L12 也存在类似参数问题。

## 根因分析

S8 的设计意图是让物体"恰好错过"——通过空间、时间、速度、高度等机制避免碰撞。但多个 level 的间距参数偏小，在物理仿真中物体实际会碰上。

### L2（temporal_separation）— 时间间隔不足

```python
# 修复前
path_directions = [(1,0,0), (-1,0,0), (0,1,0), (0,-1,0)]
distance = 1.8 + i * 0.35 * speed

# 修复后
path_directions = [
    (1.0, 0.0, 0.0),
    (0.309017, 0.951057, 0.0),
    (-0.809017, 0.587785, 0.0),
    (-0.809017, -0.587785, 0.0),
    (0.309017, -0.951057, 0.0),
]
distance = 1.8 + i * 1.5 * speed
```

补充：仅把 `0.35` 改成 `1.5` 仍不够。旧路径包含反向同线运动，物体虽然不同时到达原点，但仍可能在同一条线上其他位置相撞。因此修复同时去掉了反向同线 head-on 路径。

### L3（speed_difference）— crossing 模式路径对撞

`crossing_time_offset` 模式中，物体从 +x/-x/+y/-y 方向向原点运动，路径在原点交叉。虽然有时间偏移（`arrival_time = 0.85 + i * 0.35`），但高速物体在弯道处仍可能碰撞。

### L5（blocked_by_obstacle）— 障碍物车道未真正隔开

物体从两侧向中间运动，障碍物本应阻挡碰撞，但车道参数未确保障碍物完全覆盖路径。

### L7（height_separation）— 高度间距不足，收敛速度过大

物体在不同 z 高度运动，但向原点收敛的速度可能导致在 xy 平面上接近时高度差不足以避免碰撞。

### L10（near_miss）— 擦肩横向偏移太小

球半径极小（0.05-0.08），但反向运动的横向偏移不足。

### L11（rotation_miss）— 旋转错开间距不足

物体间距 1.2m，旋转导致的接触面变化不足以避免碰撞。

### L12（external_impulse）— 冲量转向不够

物体从 (-1.4, 0) 和 (1.4, 0) 向原点运动，冲量参数偏小，转向不足以避免碰撞。

## Codex 修复内容

| Level | 修复措施 |
|-------|----------|
| L2 | 距离乘数 0.35→1.5；路径改为五方向非反向同线，保留“先后经过同一区域”的时间分离意图 |
| L3 | 去掉 head-on 对撞路径，提高 crossing 速度下限，到达间隔 0.35s→0.55s |
| L5 | 障碍物车道真正隔开 |
| L7 | 改为不同高度层 + 平行 lane 漂移，避免随机向心聚合后落地相撞；`main_variable` 改为 `z_and_lane_separation`，显式记录 z 与 xy lane 共同分离 |
| L10 | 加宽擦肩横向偏移 |
| L11 | x 间距 1.2→1.6，y lane 扩到 `[-0.75, 0.75, 1.75]`，覆盖 seed=42 的旋转圆柱边界情况 |
| L12 | 两物体、更早更强横向冲量、起始距离 1.4→1.8 |
