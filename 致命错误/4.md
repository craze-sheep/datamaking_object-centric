# 致命错误 4：S3 L1 cube 嵌入 ramp 导致分割图全零

## 问题描述

S3（斜面物理）的 L1（倾角影响）中，cube 被放置在 ramp 表面时，**几何上嵌入了 ramp 内部**，导致 Blender 的 segmentation layer 将 cube 的像素全部分配给 ramp，cube 的分割 mask 36 帧全零。

**发现位置**：S3/L1/26（同物理样本的 3 个视角 25/26/27 全部受影响）

## 根因分析

### 放置逻辑

```python
# generate_s3_dataset.py L422-430
surf_pos = ramp_surface_point(ramp_s, ramp_y, angle, ramp_size)
normal = ramp_normal(angle)
size = (0.24, 0.24, 0.24)
pos = (surf_pos[0] + normal[0] * size[2] / 2,
       surf_pos[1] + normal[1] * size[2] / 2,
       surf_pos[2] + normal[2] * size[2] / 2)
```

`ramp_surface_point` 计算的是斜面的**理论表面**位置，但 ramp 是有厚度的实体（size 2.4×1.0×0.12），不是无限薄的面。沿法线偏移 `cube_half_height=0.12` 后，cube 仍然嵌入 ramp 内部。

### 数据证据

```text
ramp_pos:  [0, 0, 0.3819]     quat: [0.994, 0, 0.1098, 0] (倾角≈12.6°)
cube_pos:  [-0.413, 0.2, 0.4008]

cube 底面 z = 0.4008 - 0.12 = 0.2808
ramp 顶面 z ≈ 0.3819 + 0.06  = 0.4419

嵌入深度 = 0.4419 - 0.2808 = 0.1611m
cube 总高度 = 0.24m → 67% 体积在 ramp 内部
```

Frame 6+ cube 滑落到地面 (z=0.12)，完全在 ramp 下方，但 ramp 倾斜后的投影仍覆盖 cube 所在的 x-y 区域，top 视角下仍被遮挡。

### 分割图表现

| 物体 | segmentation_id | frame 1 mask 像素数 |
|------|----------------|-------------------|
| ground | 1 | 8844 ✅ |
| ramp | 3 | 1560 ✅ |
| cube | 2 | **0** ❌ |

RGB 渲染图中 cube 可见（视觉模型能识别），但 segmentation layer 中重叠区域的像素只分配给最前面的表面（ramp），cube 拿不到属于自己的像素。

## 影响范围

**受影响的 level**：所有使用 `ramp_surface_point()` 放置动态物体的组合（S3 L1-L9）

**症状严重程度**：
- S3 L1-L6/L9：cube/cylinder 等可能明显嵌入 ramp，严重时动态物体 segmentation 全零。
- S3 L7/L8：sphere 不一定出现全零 mask，但初始接触面同样由错误的 `ramp_surface_point()` 决定，已随统一公式一起修复。
- 其他 S 级别：S2/S4/S5 无 ramp 或 ramp 使用方式不同，不属于此 bug。

**未验证**：旧数据中各样本的 mask 受倾角、ramp_s、物体尺寸和视角影响，部分样本可能只是 visible_area 偏小，而非完全不可见。

## 修复方案

已修复：`task/task6-脚本编写/generate_s3_dataset.py` 中的 `ramp_surface_point()` 现在返回 ramp 的**真实外侧顶面点**，后续 cube/sphere/cylinder 仍按各自半高或半径沿法线偏移。

关键修正有两点：

1. `s` 方向的 z 符号修正。Kubric 当前 ramp 四元数下，downhill 方向是 `(cos(angle), 0, -sin(angle))`，旧代码使用 `+ s * sin(angle)`，方向反了。
2. ramp 半厚度沿法线加入 `ramp_surface_point()`，避免每个物体放置处都漏加 ramp 自身厚度。

```python
def ramp_surface_point(s, y, incline_angle, ramp_size):
    cos_a = math.cos(incline_angle)
    sin_a = math.sin(incline_angle)
    normal = ramp_normal(incline_angle)
    half_thickness = ramp_size[2] / 2.0
    center_z = ramp_size[2] + 0.5 * ramp_size[0] * sin_a
    x = s * cos_a + normal[0] * half_thickness
    z = center_z - s * sin_a + normal[2] * half_thickness
    return (x, y, z)
```

注意：不使用 `extra_offset = ramp_half_thickness * cos(angle)`。偏移是沿法线方向的标量，`cos(angle)` 已经体现在 `normal[2]` 里；半厚度应直接作为法线方向距离加入。
