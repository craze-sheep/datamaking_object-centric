# V-Net: 基于 Dice Loss 的全卷积体积分割网络

## 基本信息
- **标题**: V-Net: Fully Convolutional Neural Networks for Volumetric Medical Image Segmentation
- **作者**: Fausto Milletari, Nassir Navab, Seyed-Ahmad Ahmadi
- **机构**: 慕尼黑工业大学 (TUM)、约翰霍普金斯大学、慕尼黑大学医院
- **年份**: 2016
- **会议**: 3DV 2016 (International Conference on 3D Vision)
- **论文链接**: https://arxiv.org/abs/1606.04797
- **代码**: https://github.com/faustomilletari/VNet (基于定制版 3D-Caffe)

## 核心贡献

1. **Dice Loss 损失函数**: 提出基于 Dice 系数的可微损失函数，直接优化分割评价指标，无需手动设置前景/背景样本权重
2. **V-Net 体积分割架构**: 首个端到端训练的 3D 全卷积网络，直接对整个 MRI 体积分割，而非逐切片处理
3. **残差学习 + 编解码结构**: 每个 stage 学习残差函数，加速收敛；左侧压缩、右侧解码，配合跳跃连接传递细粒度特征
4. **卷积替代池化**: 用 stride-2 卷积替代 max-pooling，降低显存占用，便于反向传播分析

## 模型架构

### Dice 系数与 Soft Dice Loss

**Dice 系数**衡量预测与 ground truth 的重叠度，范围 [0, 1]：

```
D = 2 * Σ(pᵢ · gᵢ) / (Σpᵢ² + Σgᵢ²)
```

- `pᵢ`: 预测的二值分割体素
- `gᵢ`: ground truth 体素
- `N`: 体素总数

**可微梯度**：

```
∂D/∂pⱼ = 2 * [gⱼ(Σpᵢ² + Σgᵢ²) - 2pⱼ(Σpᵢgᵢ)] / (Σpᵢ² + Σgᵢ²)²
```

**Dice Loss = 1 - D**，直接最小化即最大化 Dice 系数。

**与交叉熵损失的对比**：

| 特性 | Dice Loss | 交叉熵 (CE) | 加权交叉熵 |
|------|-----------|-------------|------------|
| 优化目标 | 直接优化 Dice 评价指标 | 逐体素分类概率 | 逐体素 + 手动权重 |
| 前景/背景不平衡 | **天然处理**，无需重加权 | 严重受影响 | 需要精心调权 |
| 样本权重 | 不需要 | 不需要 | 需要手动设置 |
| 实验 Dice | **0.869** | 0.739 | — |
| 适用场景 | 医学分割（前景占比小） | 类别平衡任务 | 需要经验调参 |

### V-Net 网络结构

- **输入**: 128×128×64 体素的 MRI 体积
- **编码路径 (左侧)**: 4 个 stage，逐级降采样（5×5×5 卷积 + stride-2 的 2×2×2 卷积），通道数逐级翻倍（16→32→64→128→256）
- **解码路径 (右侧)**: 对称上采样（2×2×2 反卷积），通道数逐级减半
- **跳跃连接**: 左侧早期特征 forwarding 到右侧，保留细粒度空间信息（类似 U-Net）
- **残差学习**: 每个 stage 的输入直接加到该 stage 最后一层的输出上
- **激活函数**: PReLU（参数化 ReLU）
- **输出**: 2 通道（前景/背景），经 softmax 逐体素生成概率图
- **最终层感受野**: 最深层 372×372×372，输出层 551×551×551（覆盖整个输入体积）

## 训练细节

- **数据集**: PROMISE 2012 前列腺 MRI 挑战赛数据集，50 个训练体积，30 个测试体积
- **输入预处理**: N4 偏差场校正 (ANTs)，重采样到统一分辨率 1×1×1.5mm
- **数据增强**:
  - 随机非线性形变（2×2×2 控制点网格 + B 样条插值，高斯扰动 σ=15 体素）
  - 直方图匹配（随机选取数据集中其他扫描的强度分布进行适配）
  - 在线生成（on-the-fly），减少存储开销
- **优化器**: Momentum = 0.99
- **学习率**: 初始 0.0001，每 25K 迭代降低一个数量级
- **Batch size**: 2（受 3D 体积高显存需求限制）
- **训练时长**: 约 48 小时 / 30K 迭代
- **推理速度**: 单个体积约 1 秒
- **硬件**: NVIDIA GTX 1080 (8GB)，64GB 内存，i7-5820K

## 实验结果

### PROMISE 2012 前列腺分割挑战赛

| 方法 | 平均 Dice | 平均 Hausdorff 距离 | 挑战赛得分 |
|------|-----------|---------------------|-----------|
| **V-Net + Dice Loss** | **0.869 ± 0.033** | **5.71 ± 1.20 mm** | **82.39** |
| V-Net + 多项式逻辑损失 | 0.739 ± 0.088 | 10.55 ± 5.38 mm | 63.30 |
| Imorphics | 0.879 ± 0.044 | 5.935 ± 2.14 mm | 84.36 |
| ScrAutoProstate | 0.874 ± 0.036 | 5.58 ± 1.49 mm | 83.49 |
| SBIA | 0.835 ± 0.055 | 7.73 ± 2.68 mm | 78.33 |

### 关键发现

1. **Dice Loss vs 交叉熵**: Dice Loss (0.869) 远超多项式逻辑损失 (0.739)，提升 **13 个百分点**，且方差更小（0.033 vs 0.088），说明 Dice Loss 训练更稳定
2. **定性对比**: Dice Loss 产生的分割结果更完整，交叉熵损失的预测严重偏向背景，前景区域大量缺失
3. **与手工特征方法竞争**: 仅用一小部分处理时间就达到了接近挑战赛最优方法的性能

## 与当前研究的关联

### Dice Loss 的广泛影响
- Dice Loss 已成为**医学图像分割的标准损失函数**，几乎所有后续工作都采用 BCE + Dice 组合
- 被扩展到多类分割（class-wise Dice Loss）、3D 体积分割等场景
- 衍生出多种变体：Generalized Dice Loss、Soft Dice Loss、Focal Dice Loss 等

### 对当前项目的启示
- 当前模型使用 **BCE + Dice** 组合损失做 mask 预测，这正是本文奠定的最佳实践
- **可调参方向**: Dice 权重系数、平滑项 epsilon 的取值
- **不平衡问题**: 在 mask 预测中前景像素占比通常很小，Dice Loss 天然适配
- **潜在改进**: 可尝试自适应 Dice 权重（学习一个可训练的权重参数），或根据场景动态调整 BCE 与 Dice 的比例
