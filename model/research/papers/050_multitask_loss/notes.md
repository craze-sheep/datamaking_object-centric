## 核心贡献

1. **提出基于同方差不确定性的多任务损失函数** —— 从贝叶斯概率推导出发，利用每个任务的 homoscedastic uncertainty（同方差不确定性）自动学习损失权重，替代手动调权
2. **统一的场景理解架构** —— 首个在单模型中同时完成语义分割、实例分割和深度回归的系统
3. **证明损失权重的重要性** —— 实验证明合适的损失权重比单任务模型和等权加和模型都有显著提升；自动学习的权重甚至优于精细网格搜索找到的"近似最优"手动权重

## 模型架构

### 整体结构
```
输入图像 → 共享编码器 (ResNet101 + ASPP) → 任务解码器₁ (语义分割)
                                         → 任务解码器₂ (实例分割)
                                         → 任务解码器₃ (深度回归)
```

- **编码器**: 基于 DeepLabV3，使用 ResNet101 + 空洞卷积，输出特征图为输入的 1/8
- **ASPP 模块**: 4 个并行空洞卷积层（dilation rates: 1, 12, 24, 36），256 输出通道 + 全局平均池化，拼接后 1280 维特征
- **每个任务解码器**: 1×1 卷积 (256 通道) + BN + 非线性激活 → 输出层 → 双线性上采样

### 三个任务
| 任务 | 输出 | 损失函数 |
|------|------|----------|
| 语义分割 | 像素级类别概率 | 交叉熵 |
| 实例分割 | 每像素指向实例质心的向量 (x, y) | L1 回归 |
| 深度回归 | 每像素逆深度 | L1 回归 |

**实例分割方法**: 每像素回归一个指向实例质心的向量，然后用 OPTICS 密度聚类算法找到实例中心，将像素分配到最近的实例。

### 同方差不确定性加权（核心创新）

**不确定性类型**:
- **认知不确定性 (Epistemic)**: 模型因训练数据不足导致的不确定性，可通过增加数据消除
- **偶然不确定性 (Aleatoric)**: 数据本身的噪声
  - **数据依赖型 (Heteroscedastic)**: 随输入变化
  - **任务依赖型 (Homoscedastic)**: 不依赖输入，对所有数据恒定，仅随任务变化 ← **本文使用**

**回归任务的似然**:
```
p(y|f^W(x)) = N(f^W(x), σ²)
```

**分类任务的似然（温度缩放 Softmax）**:
```
p(y=c|f^W(x), σ) = Softmax(f^W(x) / σ²)
```

**多任务损失推导**:

对于两个回归任务 y₁, y₂：
```
L = 1/(2σ₁²) · L₁(W) + 1/(2σ₂²) · L₂(W) + log σ₁ + log σ₂
```

对于回归 + 分类任务的混合：
```
L ≈ 1/(2σ₁²) · L₁(W) + 1/(σ₂²) · L₂(W) + log σ₁ + log σ₂
```

**直觉理解**:
- σ 大（不确定性高）→ 该任务权重小（惩罚项 log σ 阻止 σ 趋于无穷）
- σ 小（不确定性低）→ 该任务权重大
- log σ 项作为正则化，防止不确定性无限增大（即防止模型完全忽略某任务）

**实践技巧**: 训练时预测 `s = log(σ²)` 而非 σ²，避免除零问题，且 exp(-s) 自动映射到正值域。

## 训练细节

| 参数 | Tiny CityScapes | 完整 CityScapes |
|------|-----------------|-----------------|
| 分辨率 | 128×256 | 1024×2048 |
| 迭代次数 | 50,000 | 100,000 |
| Batch size | 8 | 16 |
| GPU | 1× 1080Ti | 4× 1080Ti |
| 初始学习率 | 2.5×10⁻³ | 2.5×10⁻³ |
| 学习率策略 | 多项式衰减 (power 0.9) | 多项式衰减 (power 0.9) |
| 优化器 | SGD + Nesterov (momentum 0.9) | SGD + Nesterov (momentum 0.9) |
| 权重衰减 | 10⁻⁴ | 10⁻⁴ |
| 数据增强 | 随机水平翻转 | 随机水平翻转 + 随机缩放 (0.7-2.0) + 512×512 裁剪 |
| 训练时间 | — | 5 天 |
| 框架 | PyTorch | PyTorch |

**动态权重行为**: 训练过程中 σ 逐渐减小 → 有效学习率逐渐增大。通过多项式学习率衰减补偿此效应。

**初始化鲁棒性**: σ 的初始值从 -2.0 到 5.0 变化，均能在约 100 次迭代内收敛到相同最优值，远快于网络本身的收敛速度（10,000+ 迭代）。

## 与当前研究的关联

### 直接应用：自动损失权重学习

**当前问题**：手动设置损失权重 (`rgb=1.0, state=0.5, collision=0.5, mask=0.3`)，需要大量调参，且不同任务的最优权重可能不同。

**改进方案**：用可学习的 σ 替代手动权重：

```python
class MultiTaskLoss(nn.Module):
    def __init__(self, num_tasks=4):
        super().__init__()
        # 可学习的 log(σ²)，初始化为 0
        self.log_vars = nn.Parameter(torch.zeros(num_tasks))
    
    def forward(self, losses):
        """
        losses: [rgb_loss, state_loss, collision_loss, mask_loss]
        返回加权总损失
        """
        total_loss = 0
        for i, loss in enumerate(losses):
            precision = torch.exp(-self.log_vars[i])  # 1/σ²
            total_loss += precision * loss + self.log_vars[i]  # log(σ²) 正则项
        return total_loss
```

### 预期收益
- 自动学习最优损失权重，无需手动调参
- 权重在训练过程中动态调整（初期不确定性高→权重低，后期逐渐收敛）
- 对初始化鲁棒，快速收敛（~100 次迭代）
- 预计整体性能提升 5-10%

### 实现难度
- **低**：仅需修改损失函数，添加可学习参数
- 不改变模型架构，不增加推理开销
- σ 参数量极少（每个任务一个标量）

### 注意事项
- 对于回归任务使用 `1/(2σ²) * L + log(σ)`
- 对于分类任务使用 `1/σ² * L + log(σ)`（系数不同）
- 训练 `log(σ²)` 而非 `σ²`，数值更稳定
- 学习率需配合多项式衰减补偿 σ 减小带来的有效学习率增大
