# Neural Message Passing for Quantum Chemistry (MPNN)

## 基本信息
- **作者**：Justin Gilmer, Samuel S. Schoenholz, Patrick F. Riley, Oriol Vinyals, George E. Dahl
- **机构**：Google Brain, Google, Google DeepMind
- **年份**：2017
- **会议**：ICML 2017 (Proceedings of the 34th International Conference on Machine Learning)
- **论文链接**：https://arxiv.org/abs/1704.01212
- **主题**：将多种图神经网络统一为消息传递框架，并应用于量子化学性质预测

## 核心贡献

1. **统一框架**：提出 Message Passing Neural Networks (MPNN)，将文献中至少 8 种已有的图神经网络模型（Duvenaud et al. 2015, GG-NN, Interaction Networks, Molecular Graph Convolutions, DTNN, Laplacian 方法等）统一抽象为"消息传递 + 读出"的通用框架
2. **SOTA 结果**：在 QM9 数据集上取得全部 13 个目标的 SOTA，其中 11/13 达到化学精度（chemical accuracy）
3. **无空间信息实验**：仅使用分子拓扑图（无 3D 坐标），在 5/13 目标上达到化学精度
4. **Towers 方法**：提出多塔（Multiple Towers）结构，允许更大的节点表示维度而不增加计算时间和内存

## 模型架构

### 总体框架

MPNN 的前向传播分为两个阶段：

**消息传递阶段**（T 个时间步）：
$$m_v^{t+1} = \sum_{w \in \mathcal{N}(v)} M_t(h_v^t, h_w^t, e_{vw})$$
$$h_v^{t+1} = U_t(h_v^t, m_v^{t+1})$$

**读出阶段**：
$$\hat{y} = R(\{h_v^T \mid v \in G\})$$

其中 $M_t$ 为消息函数，$U_t$ 为节点更新函数，$R$ 为读出函数，均为可学习的可微分函数。$R$ 对节点状态集合的操作必须对节点排列不变，以保证 MPNN 对图同构的不变性。

### 消息函数（Message Functions）

论文比较了三种消息函数变体：

- **矩阵乘法（Matrix Multiply）**：$M(h_v, h_w, e_{vw}) = A_{e_{vw}} h_w$，其中 $A_{e_{vw}}$ 是每种离散边类型对应的可学习矩阵（来自 GG-NN）
- **边网络（Edge Network）**：$M(h_v, h_w, e_{vw}) = A(e_{vw}) h_w$，其中 $A(e_{vw})$ 是将边向量映射为 $d \times d$ 矩阵的神经网络，支持连续值边特征
- **配对消息（Pair Message）**：$m_{wv} = f(h_w^t, h_v^t, e_{vw})$，消息同时依赖源节点和目标节点（来自 Interaction Networks），但实验中表现不如 Edge Network

**关键发现**：Edge Network 在大多数目标上优于 Pair Message（平均误差比 1.53 vs 3.98）。

### 节点更新函数（Vertex Update Functions）

- 所有实验统一使用 **GRU**（Gated Recurrent Unit）作为更新函数：$U = \text{GRU}(h_v^t, m_v^{t+1})$
- 所有时间步共享权重（weight tying），实验发现这比不共享权重更有效，配合更大的隐藏维度 $d$ 效果更好

### 读出函数（Readout Functions）

- **GG-NN 读出**：$R = \sum_{v \in V} \sigma(i(h_v^T, h_v^0)) \odot j(h_v^T)$，其中 $i, j$ 为神经网络，$\odot$ 为逐元素乘法
- **Set2Set**：先对 $(h_v^T, x_v)$ 做线性投影，经 M 步计算后产生对节点排列不变的图级嵌入 $q_t^*$，再通过神经网络输出。Set2Set 的表达力更强，在实验中表现更好

### 虚拟图元素（Virtual Graph Elements）

- **虚拟边（Virtual Edges）**：为不相连的节点对添加单独的"虚拟"边类型，使信息可在图中远距离传播
- **Master 节点**：添加一个与所有输入节点相连的隐主节点，拥有独立维度 $d_{\text{master}}$ 和独立更新权重，作为全局"草稿空间"。复杂度为 $O(|E|d^2 + nd_{\text{master}}^2)$

### Multiple Towers

将 $d$ 维节点嵌入拆分为 $k$ 个 $d/k$ 维子嵌入，各自独立运行消息传递，再通过混合网络 $g$ 融合：
$$h_v^{t,1}, h_v^{t,2}, \ldots, h_v^{t,k} = g(\tilde{h}_v^{t,1}, \tilde{h}_v^{t,2}, \ldots, \tilde{h}_v^{t,k})$$

- 保持对节点排列的不变性
- 允许不同子图副本在传播阶段相互通信
- 总时间复杂度 $O(n^2 d^2/k)$，$k=8, d=200$ 时推理速度提升约 2 倍
- Towers 还能提升泛化性能（类似集成学习效果）

## 训练细节

- **数据集**：QM9，134k 个有机小分子（H, C, N, O, F，最多 9 个重原子），每个分子 13 个 DFT 计算的量子化学性质
- **数据划分**：10k 验证 / 10k 测试 / 其余训练
- **优化器**：SGD + Adam，batch size 20，训练 300 万步（约 540 个 epoch）
- **学习率**：初始均匀采样自 $[10^{-5}, 5 \times 10^{-4}]$，线性衰减（从训练 10%~90% 处开始），衰减因子 $F \in [0.01, 1]$
- **超参搜索**：每个模型-目标组合进行 50 次随机搜索
- **消息传递步数**：$T \in [3, 8]$（实验中 $T \geq 3$ 均可）
- **Set2Set 计算步数**：$M \in [1, 12]$
- **目标归一化**：均值 0，方差 1
- **损失函数**：最小化 MSE，评估指标为 MAE
- **训练策略**：单独训练每个目标（per-target）优于联合训练 13 个目标（部分目标提升达 40%）
- **最佳变体**：Edge Network 消息函数 + Set2Set 读出 + 显式氢原子节点（enn-s2s）
- **集成**：取验证误差最低的 5 个模型进行集成（enn-s2s-ens5）

### 输入特征

**节点特征**（Table 1）：
| 特征 | 描述 |
|------|------|
| Atom type | H, C, N, O, F（one-hot） |
| Atomic number | 质子数（整数） |
| Acceptor | 是否接受电子（二值） |
| Donor | 是否捐赠电子（二值） |
| Aromatic | 是否在芳香体系中（二值） |
| Hybridization | sp, sp2, sp3（one-hot） |
| Number of Hydrogens | 氢原子数（整数） |

**边特征**三种方案：
1. **化学图**：离散键类型（单键、双键、三键、芳香键）
2. **距离分桶**：将原子对距离分为 10 个桶（[0,2], [2,6] 均分 8 桶，[6,∞]），邻接矩阵字母表大小 14
3. **原始距离特征**：5 维向量（欧氏距离 + 键类型 one-hot），用于 Edge Network 消息函数

## 关键实验结论

1. **Edge Network > Pair Message**：边网络消息函数在绝大多数目标上优于配对消息（可能因 Pair Message 训练更难）
2. **Set2Set > 简单求和读出**：Set2Set 能更好地捕获全局图级信息
3. **显式氢原子很重要**：将氢原子作为图中显式节点（图节点从 ~9 增至 ~29），训练时间增加约 10 倍，但性能显著提升
4. **单独训练优于联合训练**：每个目标单独训练一个模型，部分目标提升达 40%
5. **Weight tying + 大维度**：共享权重配合更大的隐藏维度比不共享权重更有效
6. **DFT 推理速度提升约 30 万倍**

## 与当前研究的关联

### 统一框架的价值

MPNN 将多种 GNN 变体统一为"消息-更新-读出"三步范式，成为后续几乎所有图神经网络工作的理论基础。包括：
- GAT（Graph Attention Network）：在消息函数中加入注意力机制
- SchNet / DimeNet：在 MPNN 框架内引入连续距离信息
- 本研究中的交互模型可视为 MPNN 的一个具体实例

### 可借鉴的设计选择

- **消息函数**：Edge Network 是处理连续边特征的有效方式
- **远距离通信**：虚拟边、Master 节点、Set2Set 读出是解决图中长距离依赖的三种不同策略
- **Towers 结构**：通过分拆-混合实现大维度的高效训练
- **输入表示**：显式建模所有原子（包括氢）和丰富的边特征非常重要

### 局限性与未来方向

- 泛化到比训练集更大的分子图仍然困难（距离分布和消息数量都随节点数变化）
- 作者建议对输入消息向量添加注意力机制以处理可变大小的图
- 对于更大分子（如 GDB-17 中的分子），Towers 变体最为有用
