当前主线是一个面向物理视频预测的 object-centric 模型：用视觉和物理状态共同编码物体，用 force-aware GNN 建模交互，再用轻量 GRU 预测未来，并同时输出状态、碰撞、mask 和 RGB。

框架速读

如果只想快速理解主线代码，可以按这 5 个阶段看。

Encoder

视觉 + 物理双流

轻量 CNN 提取图像特征，按 GT mask 做 per-object pooling；物理分支编码属性、状态和派生物理量。

GNN

显式交互推理

每个物体是节点，边特征来自力、相对位置、相对速度、距离和力大小，使用 masked attention 聚合邻居。

Temporal

GRU + 时序注意力

对每个物体独立编码历史，再自回归生成未来 token；history self-attention 增强对关键历史帧的访问。

Decoder

多头输出

同一组 future tokens 同时解码 state、collision logits、collision effect、mask 和 RGB。

Loss

物理约束训练

总损失融合 RGB、SSIM、state、collision、mask、能量守恒和碰撞效果监督。

模块设计

这些是当前 `ai_model/` 主线中已经合入的设计，不包含暂缓的大分支。

PhysicsObjectEncoder

输出 [B, T, N, fused_dim] object tokens。

  • 视觉分支：CNN + mask 平均池化。
  • 物理分支：属性 MLP + 状态 MLP。
  • 派生特征：动能、势能、动量大小、角动量 proxy。

ForceAwareGNN

默认 3 层 message passing，带 residual 和 LayerNorm。

  • 边输入 14 维：双向力、相对位置/速度、距离、力大小。
  • GAT-style attention 让接触/强相互作用 pair 权重更高。
  • FP16 mask 使用 -1e4，降低 AMP 溢出风险。

TemporalGRU

替代重 Transformer，显存更友好。

  • 每个物体共享 GRU 权重。
  • top recurrent state 接 history attention。
  • Scheduled Sampling 已保留接口但默认禁用。

MultiHeadDecoder

一个 token 流对应多种监督目标。

  • StateHead 输出 16 维物理状态。
  • CollisionHead 输出 pair logits 和 3 维 effect。
  • MaskHead 解码 per-object mask，RGBDecoder 合成场景。

PhysicsLoss

主损失使用 Kendall 多任务不确定性加权。

  • RGB = L1 + 0.5 MSE + SSIM，可选 LPIPS。
  • Collision = Focal BCE + pos_weight。
  • 额外加入 energy 和 collision effect。

Train Pipeline

训练脚本支持外部 train/test 根目录。

  • TensorBoard 只写 loss，中文标签。
  • 支持 AMP、resume、独立 checkpoint 目录。
  • 当前用 /train 和 /test 全量样本。

暂不进主线

这些方向保留计划，等独立实验验证后再决定是否合入。

方向 当前处理 暂缓原因
Scheduled Sampling 接口保留，默认禁用 需要 decoder-feedback teacher path，不能泄漏未来 RGB/mask/force。
DINOv2 Encoder 保留在 experiments 原型 patch token 与当前 GT mask ROI pooling 接口还要重构。
Mamba Temporal 保留在 experiments 原型 依赖 CUDA 编译，短序列收益不确定。
Slot Attention / SAVi 保留在 experiments 原型 slot 无序，需要 matching 或改成 slot-centric 数据流。
