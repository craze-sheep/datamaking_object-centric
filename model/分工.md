## 任务执行流程

**每完成一个子任务，Claude Code 评审，通过后标记完成，进入下一任务**：

```
1. Hermes + OpenCode 协作完成子任务
   - 设计文档：Hermes写 → OpenCode审 → Hermes改 → 直到双方确认
   - 代码实现：Hermes写测试 → Hermes写代码 → OpenCode审查 → Hermes改
   - 同步记录：设计思路、决策理由、迭代过程

2. Claude Code 评审
   - 审查设计是否合理、实现是否正确
   - 指出问题或确认通过
   - 评审结果记录到对应文档中

3. 如果不通过
   - Hermes + OpenCode 根据反馈修改
   - 记录修改原因和过程
   - Claude Code 再次评审
   - 重复直到通过

4. 如果通过
   - Claude Code 在分工.md中标记该任务已完成 ✓
   - 记录最终评审结论
   - 进入下一个任务

5. 重复1-4，直到所有任务完成
```

**为什么需要 Claude Code**：
- Hermes 和 OpenCode 都是 mimo2.5，视角相同，可能存在盲区
- Claude Code 是不同模型，能发现前两者看不到的问题
- 最终质量把关
