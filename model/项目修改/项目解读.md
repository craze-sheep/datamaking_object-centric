# PhysicsObjectGraphPredictor — 物理感知目标图预测模型

## 一、项目概述

### 1.1 定位

这是一个**基于物体的物理视频预测模型**（Object-Centric Physics Video Predictor）。给定过去 12 帧的 RGB 图像及物体物理状态，预测未来 12 帧的运动轨迹、碰撞关系、分割掩码和渲染图像。

### 1.2 核心思路

把场景中的每个物体（最多 7 个）当作图中的节点，用物理力矩阵构建边，用 GNN 建模物体间交互，用 GRU 建模时序演化，最后通过多头解码器输出各种预测。

### 1.3 关键设计选择

| 设计维度 | 本模型 | 典型 baseline |
|---------|--------|--------------|
| 物体表示 | 双流编码（视觉CNN + 物理MLP） | 单流统一编码 |
| 交互建模 | 力感知 GNN（显式力向量作为边特征） | 密集 pairwise MLP |
| 时序建模 | GRU + 注意力增强 | Transformer encoder-decoder |
| 物理先验 | 显式编码质量/摩擦/动能/势能 | 隐式学习 |
| RGB 解码 | 合成式渲染（mask × 颜色 + 背景） | 像素级生成 |

### 1.4 模型规模

- **参数量**: 1,058,910 (~1M，轻量级)
- **显存占用**: batch_size=16 时约 38.7%（8GB GPU，RTX 4060 Laptop）
- **每 epoch 时间**: ~2.3 小时（25504 训练样本）
- **训练配置**: fused_dim=96, gru=96, gnn=96, 3层GNN, 2层GRU

## 二、整体架构

### 2.1 数据流总览

```
输入 (12帧历史)
├─ RGB 图像:      [B, 12, 3, 128, 128]
├─ 分割掩码:      [B, 12, 7, 128, 128]
├─ 物体属性:      [B, 7, 14]           (尺寸/摩擦/质量/弹性/类型)
├─ 动态状态:      [B, 24, 7, 16]       (位置/四元数/速度/角速度/力)
├─ 力矩阵:        [B, 24, 7, 7, 3]    (物体间作用力向量)
└─ 有效掩码:      [B, 7]              (哪些物体存在)
     │
     ▼
┌──────────────────────────────────────────────────┐
│  1. 双流编码器 PhysicsObjectEncoder               │
│     视觉流(CNN+ROI) + 物理流(属性+状态) → 融合    │
│     输出: [B, T, 7, 96]                          │
├──────────────────────────────────────────────────┤
│  2. 力感知 GNN ForceAwareGNN                      │
│     3层消息传递，力矩阵构建边特征                  │
│     输出: [B, T, 7, 96]                          │
├──────────────────────────────────────────────────┤
│  3. 时序 GRU TemporalGRU                          │
│     编码历史12帧 → 自回归解码未来12帧              │
│     输出: [B, 12, 7, 96]                         │
├──────────────────────────────────────────────────┤
│  4. 多头解码器 MultiHeadDecoder                    │
│     状态头 + 碰撞头 + 掩码头 + RGB头               │
└──────────────────────────────────────────────────┘
     │
     ▼
输出 (12帧预测)
├─ state_pred:         [B, 12, 7, 16]         物理状态预测
├─ collision_logits:   [B, 12, 7, 7]          碰撞分类 logit
├─ collision_effect:   [B, 12, 7, 7, 3]       碰撞效果力
├─ mask_logits/prob:   [B, 12, 7, 128, 128]   分割掩码
└─ rgb_pred:           [B, 12, 3, 128, 128]    渲染图像
```

### 2.2 端到端前向传播

```python
# model.py - PhysicsObjectGraphPredictor.forward()
def forward(self, batch):
    enc_out = self.encoder(batch)              # 1. 双流编码
    interacted = self.interaction(tokens, ...) # 2. GNN 交互
    temporal_out = self.temporal(interacted, ...) # 3. GRU 时序
    pred = self.decoder(future_tokens, ...)    # 4. 多头解码
    return pred
```

### 4.3 双流编码器 — encoder.py

包含 4 个类，按调用顺序：

#### (1) VisualEncoder — 视觉特征提取

```
RGB [B, T, 3, 128, 128]
  → reshape [B*T, 3, 128, 128]
  → Conv2d(3→32, stride=2) + GroupNorm + GELU
  → Conv2d(32→64, stride=2) + GroupNorm + GELU
  → Conv2d(64→128, stride=2) + GroupNorm + GELU
  → Conv2d(128→128, stride=2) + GroupNorm + GELU
  → reshape [B, T, 128, 8, 8]
```

总下采样 16 倍（128 → 8），使用 GroupNorm 而非 BatchNorm。

#### (2) MaskedROIPooler — 掩码 ROI 池化

不使用 bbox ROI pooling，而是用像素级分割掩码做 masked average pooling：

```
feat_map [B*T, C, 8, 8] + masks [B*T, N, 128, 128]
  → 下采样 masks 到 8×8
  → 加权平均: pooled = Σ(feat × mask) / Σ(mask)
  → 线性投影 [C] → [visual_out_dim]
  → tokens [B*T, N, visual_out_dim]
```

每个物体从特征图中提取自己的特征，精度高于 bbox 方式。

#### (3) PhysicsEncoder — 物理特征编码

```
静态属性 [B, N, 14] → MLP → attr_feat [B, N, 64]

动态状态 [B, T, N, 16] + 派生物理量(4维)
  → MLP → state_feat [B, T, N, 64]

融合: concat(attr_feat, state_feat) → MLP → physics_tokens [B, T, N, 96]
```

**派生物理量**（`_derived_physics_features`）：
- 动能: `0.5 × m × |v|²`
- 势能: `m × g × h`
- 动量: `m × |v|`
- 角动量: `m × |ω|`

这 4 个特征让 MLP 直接获得力学量，无需从原始状态重新推导。

#### (4) PhysicsObjectEncoder — 双流融合

```
visual_tokens [B, T, N, 96] + physics_tokens [B, T, N, 96]
  → concat [B, T, N, 192]
  → Linear(192 → 96) + LayerNorm + GELU
  → fused tokens [B, T, N, 96]
  → 乘以 valid_mask 置零无效物体
```

### 4.4 力感知 GNN — interaction.py

#### 图结构
- **节点**: 物体 token [B, T, N, 96]
- **边**: 力矩阵 [B, T, N, N, 3]（物体间作用力向量）

#### (1) ForceAwareEdgeNetwork — 边特征构建

为每对物体 (i, j) 构建 14 维边特征：

```
边输入 = concat(
  force_ij,           # j 对 i 的力 [3]
  force_ji,           # i 对 j 的力 [3]
  pos_i - pos_j,      # 相对位置 [3]
  vel_i - vel_j,      # 相对速度 [3]
  ||pos_i - pos_j||,  # 距离 [1]
  ||force_ij||,       # 力大小 [1]
)                     # 共 14 维
  → MLP(14 → 64 → 64)
  → edge_feat [B, T, N, N, 64]
```

其中位置和速度从原始 dyn_state 的索引 [0:3] 和 [7:10] 提取。

#### (2) GNNSingleLayer — 单层消息传递

```
消息函数: MLP(concat(node_i, node_j, edge_ij)) → message
注意力:   GAT风格，MLP → attn_logit → softmax → 权重
聚合:     注意力加权求和 Σ(attn × message)
更新:     GRUCell(aggregated, old_state) → new_state
```

- 消息输入维度: `96 × 2 + 64 = 256`
- 使用 LeakyReLU 注意力，让碰撞/接触物体的消息权重更大
- 自环排除，无效物体排除

#### (3) ForceAwareGNN — 多层堆叠

```
3 × (GNNSingleLayer + LayerNorm + 残差连接)
```

边特征只计算一次，3层共享。

### 4.5 时序 GRU — temporal.py

#### (1) 编码历史 (`encode_history`)

```
tokens [B, 12, N, 96]
  → permute+reshape [B*N, 12, 96]
  → Linear(96 → 96) 投影（如果维度不匹配）
  → 2层 GRU: out [B*N, 12, 96], h [2, B*N, 96]
  → 多头注意力增强 top layer:
      attn_out = MHA(gru_out, gru_out, gru_out)
      h[-1] = enhanced[:, -1]  # 用 attention 后的最后一步
  → reshape h_last [B, N, 2, 96]
  → 乘以 valid_mask 置零
```

关键设计：只用注意力增强 GRU 最顶层隐藏状态，底层保持原始循环状态。

#### (2) 解码未来 (`decode_future`) — 自回归

```
初始: x = last_observed_token, h = h_last

for t in range(12):
    out, h = GRU(x, h)     # 单步
    future_tokens.append(out)
    x = out                # 自回归：输出即下一步输入

future_tokens [B, 12, N, 96]
```

支持 teacher forcing（当前关闭，`use_scheduled_sampling=False`），因为没有 decoder-feedback teacher 路径，直接用未来 encoder token 会泄露目标信息。

### 4.6 多头解码器 — decoder.py

#### (1) StateHead — 物理状态预测

```
token [B, 12, N, 96]
  → MLP(96 → 256 → 256 → 16)
  → state_pred [B, 12, N, 16]
```

输出与输入状态同维度：位置(3) + 四元数(4) + 速度(3) + 角速度(3) + 力(3)。

#### (2) CollisionHead — 碰撞预测

```
拼接 [node_i, node_j, |node_i - node_j|] = 288 维
  → MLP(288 → 64 → 1) → collision_logit [B, 12, N, N]
  → MLP(288 → 64 → 3) → collision_effect [B, 12, N, N, 3]
```

碰撞效果力是单独的 3 维输出，用于预测碰撞时的力方向和大小。

#### (3) MaskHead — 分割掩码预测

```
token [B, 12, N, 96]
  → Linear(96 → 32×8×8)
  → reshape [B*12*N, 32, 8, 8]
  → ConvTranspose2d(32→32, stride=2) + GN + GELU  → 16×16
  → ConvTranspose2d(32→16, stride=2) + GN + GELU  → 32×32
  → ConvTranspose2d(16→8, stride=2) + GN + GELU   → 64×64
  → ConvTranspose2d(8→1, stride=2)                 → 128×128
  → mask_logits [B, 12, N, 128, 128]
```

4 层反卷积逐步上采样，从 8×8 到 128×128。

#### (4) RGBDecoder — 合成式渲染

不从零生成像素，而是用掩码和颜色合成：

```
外观头: token → MLP(96→128→3) + Sigmoid → appearance [B, 12, N, 3]
背景解码: mean_token → Linear → ConvTranspose2d×4 → background [B, 12, 3, 128, 128]

合成:
  foreground = Σ_i(mask_i × appearance_i)
  total_mask = Σ_i(mask_i).clamp(0, 1)
  rgb_pred = foreground + background × (1 - total_mask)
```

每个物体只有一个 RGB 颜色（3维），不是像素级生成，大幅降低计算量。

#### (5) MultiHeadDecoder — 组合

```python
state_pred     = state_head(tokens)
collision_out  = collision_head(tokens)
mask_logits    = mask_head(tokens)
mask_prob      = sigmoid(mask_logits)
rgb_pred       = rgb_decoder(tokens, mask_prob)
```

还计算 `pair_mask`：排除自边、padding 物体、static-static 对。

### 4.7 多任务损失 — loss.py

#### 损失项总览

| 编号 | 名称 | 计算方式 | 权重 |
|-----|------|---------|------|
| 01 | 总损失 | 加权和（含不确定性加权） | - |
| 02 | RGB 重建 | L1 + 0.5×MSE | 1.0 |
| 03 | SSIM | 自实现 SSIM loss | 0.1 |
| 04 | LPIPS | AlexNet 感知损失 | 0.0（关闭） |
| 05 | 物理状态 | Smooth L1，分量加权 | 0.5 |
| 06 | 碰撞分类 | Focal BCE | 0.5 |
| 07 | 碰撞效果 | Smooth L1 on force | 0.05 |
| 08 | 分割掩码 | BCE + Dice | 0.3 |
| 09 | 能量守恒 | \|KE[t+1] - KE[t]\| 均值 | 0.01 |

#### 各损失详解

**RGB 损失** (rgb_loss):
```
rgb_loss = L1(pred, target) + 0.5 × MSE(pred, target)
         + 0.1 × SSIM(pred, target)
         + 0.0 × LPIPS(pred, target)
```
目标 RGB 从 [-1,1] 反归一化到 [0,1] 再计算。

**状态损失** (state_loss):
```
state_diff = SmoothL1(pred, target)  # [B, Tp, N, 16]
state_diff = state_diff × component_weights  # 分量加权
state_loss = masked_mean(state_diff, dynamic_mask)
```
分量权重：位置 1.0, 四元数 0.5, 速度 0.5, 角速度 0.25, 力 0.25。
只在动态物体上计算（排除静态物体如地面）。

**碰撞分类损失** (collision_loss):
```
collision_labels = (||force|| > threshold).float()  # 从力矩阵生成标签
pos_weight = neg_count / pos_count  # 正样本重加权
bce = BCE_with_logits(logits, labels, pos_weight)
focal_weight = (1 - p_t)^2.0
collision_loss = masked_mean(focal_weight × bce, pair_mask)
```
使用 focal loss 解决正负样本不平衡（大部分物体对不碰撞）。

**碰撞效果损失** (effect_loss):
```
只在真正碰撞的 pair 上计算
effect_loss = SmoothL1(effect_pred, force_target)
```

**分割掩码损失** (mask_loss):
```
mask_loss = BCE(logits, target) + Dice(prob, target)
```

**能量守恒损失** (energy_loss):
```python
vel = state_pred[..., 7:10] * vel_scale  # 反归一化
mass = obj_attrs[..., 7:8]
kinetic_energy = 0.5 × mass × |vel|²
energy_diff = |KE[t+1] - KE[t]|
energy_loss = masked_mean(energy_diff, dynamic_mask)
```
惩罚动能在相邻帧间的突变，鼓励物理一致性。

#### 不确定性加权

```python
if use_uncertainty_weighting:
    # 可学习的 log_var，初始为 0
    total = Σ exp(-log_var_i) × loss_i + log_var_i
```
Kendall 多任务不确定性加权：损失大的任务自动降低权重，防止某个 loss 主导梯度。

#### 掩码规则
- 填充物体 (valid_mask=False): 排除所有损失
- 静态物体 (static=True): 排除状态损失
- 静态-静态对: 排除碰撞损失
- 自环 (i==i): 排除碰撞损失
- 无有效物体: 返回 0，避免 NaN

### 4.8 训练脚本 — train.py

#### 训练流程

```
1. 解析参数 → 构建 config
2. 自动调 batch_size: 从小到大尝试，直到 VRAM 达到 82%
3. 构建模型 + 优化器 + AMP GradScaler
4. 加载数据集（train / val）
5. 训练循环:
   for epoch in epochs:
       train_one_epoch()  # 训练
       validate()         # 验证
       save_checkpoint()  # 保存
6. TensorBoard 日志记录
```

#### 关键训练配置

| 配置 | 值 |
|-----|---|
| 优化器 | AdamW (lr=1e-3, weight_decay=1e-4) |
| 梯度裁剪 | max_norm=1.0 |
| AMP | 开启 (torch.cuda.amp) |
| 批量大小 | 16（自动调优） |
| 总 epoch | 10 |
| 日志间隔 | 每 20 步 |

#### 数据划分

按场景（scene）分层划分：
- 训练集: 70%
- 验证集: 15%
- 测试集: 15%

split='all' 时使用全部数据（当前训练使用）。

| 物体属性 | [B, N, 14] | 未归一化 |
| 动态状态 | [B, T, N, 16] | 归一化（除以 scale） |
| 力矩阵 | [B, T, N, N, 3] | 归一化（/50） |
| 有效掩码 | [B, N] | bool |

其中 B=batch_size, T=24(12历史+12预测), N=7(最大物体数)。

## 六、已知问题与改进方向

### 6.1 能量守恒损失震荡

训练曲线显示能量守恒损失的变异系数 (CV=1.87) 远高于其他损失（0.05~0.58），且尖刺逐 epoch 加剧：
- Epoch 2: max spike = 0.092, >0.1 占比 0%
- Epoch 5: max spike = 0.585, >0.1 占比 17%

原因：`0.5 × m × v²` 中的平方项放大了速度预测误差。

可能的改进：
1. 用 Huber loss 替代 L1，抑制大值
2. 能量守恒 loss 权重随 epoch 衰减
3. 检查 vel_scale 是否与数据归一化的 std 对齐

### 6.2 验证集过拟合迹象

- 能量守恒验证损失后 2 epoch 持续上升 (0.0028 → 0.0048 → 0.0059)
- 分割掩码验证损失微弱回升 (0.0240 → 0.0241)

### 6.3 LPIPS 损失始终为 0

当前 `lpips_weight=0.0`，如果需要启用感知损失，需设置为正值（如 0.01）。

### 6.4 归一化 scale 硬编码

state_std 和 force_std 是手动估计的固定值，不是从数据统计计算的。建议：
1. 跑一遍训练集统计实际 mean/std
2. obj_attrs（质量、尺寸等）未归一化，不同量纲混在一起影响 MLP 学习效率
