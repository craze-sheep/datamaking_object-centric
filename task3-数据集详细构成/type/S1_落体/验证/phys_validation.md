## 二、各 Level 物理推导与合理性判断

### Level 1：自由落体高度的影响 (h -> 落地时间)

**当前设定**：sphere, radius=0.22m, z=[0.6,0.9,1.3,1.8,2.4]m, 12fps。

自由落体时间由球底部离地高度决定：

```
h = z - radius
t = sqrt(2h/g)
```

| z | 底部离地 h | t_fall | 12fps帧位置 |
|:---:|:---:|:---:|:---:|
| 0.6 | 0.38m | 0.278s | 3.34帧 |
| 0.9 | 0.68m | 0.373s | 4.47帧 |
| 1.3 | 1.08m | 0.469s | 5.63帧 |
| 1.8 | 1.58m | 0.568s | 6.81帧 |
| 2.4 | 2.18m | 0.667s | 8.00帧 |

相邻高度的落地时间差为 0.094s、0.097s、0.098s、0.099s，均大于 12fps 单帧间隔 0.083s。原先相邻高度落地帧重叠的问题已通过减少并拉开高度取值修复。✓

物理组合数：

```
z(5) × x(3) × y(3) × color(4) = 180 → 需~100 ✓
```

### Level 2：竖直初速度的影响 (v0z -> 落地时间与轨迹)

**当前设定**：z=[0.9,1.2,1.6,2.0], v0z=[-1.2,-0.8,-0.4,0,0.4,0.8,1.2]。

设竖直向上为正，球底部离地高度 h=z-r，落地时间满足：

```
h + v0z * t - 0.5 * g * t^2 = 0
```

极端组合均在 3s 内落地：

| 场景 | t_fall | 判断 |
|---|---:|---|
| z=0.9, v0z=-1.2m/s | 0.270s | 可见 |
| z=0.9, v0z=0 | 0.373s | 可见 |
| z=0.9, v0z=+1.2m/s | 0.515s | 可见 |
| z=2.0, v0z=-1.2m/s | 0.493s | 可见 |
| z=2.0, v0z=0 | 0.603s | 可见 |
| z=2.0, v0z=+1.2m/s | 0.738s | 可见 |

物理组合数：

```
z(4) × v0z(7) × color(4) = 112 → 需~100 ✓
```

### Level 3：反弹规律 (恢复系数 -> 反弹高度衰减)

**当前设定**：ground.restitution=[0,0.3,0.5,0.8,1.0]，object.restitution=1.0。

有效恢复系数：

```
e_eff = e_ground × e_object = e_ground
h_rebound = h_drop × e_eff^2
```

以最高释放点 z=2.0、h_drop=1.78m 为例：

| e_ground | 首次反弹高度 | 视觉判断 |
|:---:|---:|---|
| 0.0 | 0.000m | 无反弹 |
| 0.3 | 0.160m | 明显可见 |
| 0.5 | 0.445m | 明显可见 |
| 0.8 | 1.139m | 明显可见 |
| 1.0 | 1.780m | 明显可见 |

原先 e_g=0.1 且 object.restitution=0.5 导致反弹小于 5mm 的问题已修复：低可见性档位被移除，object.restitution 固定为 1.0，使标签与 ground.restitution 一致。✓

物理组合数：

```
e_g(5) × z(4) × v0z(3) × color(4) = 240 → 需~100 ✓
```

### Level 4：水平位置无关性与水平抛体独立性

**当前设定**：位置子任务约 50 个样本，水平抛体子任务约 50 个样本。

位置子任务中 vx=vy=0，竖直运动：

```
z(t) = z0 - 0.5 * g * t^2
```

落地时间只由 z0 和 radius 决定，与 x/y 无关。✓

水平抛体子任务中：

```
t_fall 只由 z 决定
dx = vx * t_fall
dy = vy * t_fall
```

当前水平速度覆盖 10 个方向/大小组合：

```
(±0.4,0,0), (0,±0.4,0), (±0.6,0,0), (0,±0.6,0), (0.45,0.45,0), (-0.45,0.45,0)
```

物理组合数：

```
位置子任务: x(5) × y(5) × z(3) = 75 → 需~50 ✓
抛体子任务: v_xy(10) × z(3) × color(4) = 120 → 需~50 ✓
```

原先“18 个抛体组合支撑 50 样本”的多样性问题已通过增加水平速度方向与大小修复。✓

### Level 5：质量无关性

自由落体加速度：

```
F = mg
a = F/m = g
```

默认无空气阻力时，质量不影响落地时间。当前 mass=[0.3,0.5,1.0,2.0,4.0] 可构成完整配对组。✓

物理组合数：

```
mass(5) × z(4) × v0z(3) × color(4) = 240 → 需~100 ✓
```

### Level 6：尺寸无关性

当前使用 release_clearance 控制球底部离地高度：

```
z_center = radius + release_clearance
fall_distance = z_center - radius = release_clearance
t = sqrt(2 * release_clearance / g)
```

因此相同 release_clearance 下，不同 radius 的落地时间一致。设计正确。✓

物理组合数：

```
radius(3) × clearance(5) × v0z(3) × mass(3) × x(3) × y(3) = 1215 → 需~150 ✓
```

### Level 7：形状泛化

sphere 与 cube 均使用 contact_offset + release_clearance 控制底部离地高度。竖直下落时间只由 release_clearance 与 v0z 决定，与形状无关；restitution>0 时形状差异主要体现在接触几何与碰撞后的旋转/反弹表现。✓

物理组合数：

```
sphere: r(3) × clearance(5) × v0z(3) × mass(3) × rest(3) × x(3) × y(3) = 3645
cube:   size(3) × clearance(5) × v0z(3) × mass(3) × rest(3) × x(3) × y(3) = 3645
合计远大于 ~150 ✓
```

## 四、最终结论

落体/抛体参数配置当前物理上可用：数量口径一致，关键现象在 12fps 下具备可区分帧，反弹高度可见，组合空间能支撑目标样本数。后续实现采样器时需要保持成组配对，不要让 color、x/y 等视觉扰动与主物理变量固定绑定。
