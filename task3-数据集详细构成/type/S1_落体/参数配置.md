# Type1：单物体落体/抛体参数配置

## 全局设置
- 视频时长：3s
- 分辨率：64 x 64
- 总帧数：36 帧
- 帧率：12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,top]
- 样本数口径：下文样本数指物理场景配置数；若每个配置渲染 2 个相机视角，视频数 = 样本数 x 2。
- 简单 level 样本数：约 100 个
- 复杂 level 样本数：约 150 个

## 通用参数池

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：按 level 指定
- 约束：spinningFriction <= rollingFriction
- 其他属性：默认值

### 物体公共参数
- object_type：[sphere,cube]
- radius：[0.18,0.22,0.28]
- size：[(0.18,0.18,0.18),(0.24,0.24,0.24),(0.30,0.30,0.30)]
- initial_quaternion：默认值 [1,0,0,0]，Kubric 格式 [w,x,y,z]
- initial_angular_velocity：[0,0,0]
- color：[red,blue,yellow,green]
- friction：[0.4]
- 其他属性：默认值

### 采样策略
- 所有 level 使用分层采样；不直接展开完整笛卡尔积。
- 主变量必须均衡覆盖，边界值优先覆盖。
- 用于验证无关性的 level 使用成组配对采样：除被验证的无关变量外，其余动力学变量保持一致。
- 视觉变量 color 与动力学变量正交采样，不能让颜色固定绑定某个高度、质量、尺寸或形状。
- 初始位置必须满足不穿透约束：
  - sphere：initial_position 的 z 分量 > radius
  - cube：initial_position 的 z 分量 > size 的 z 分量 / 2
- 衍生标签统一记录：
  - first_contact_time
  - first_contact_frame
  - effective_restitution
  - landing_position
  - rebound_height
  - max_height_after_release
  - is_static_at_end

## Level 1：自由落体高度的影响（h -> 落地时间）
- 难度：简单
- 样本数：约 100
- 目标：只学习释放高度对首次接触时间的影响。

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0]

### 物体参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[-0.2,0,0.2]
  - y：[-0.2,0,0.2]
  - z：[0.6,0.9,1.3,1.8,2.4]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[0]
- friction：[0.4]
- color：[red,blue,yellow,green]

### 采样约束
- initial_position 的 z 分量为主变量，5 个高度均衡覆盖。
- x/y/color 只作为视觉扰动，不参与落地时间判断。
- 每个高度至少 20 个样本。

## Level 3：反弹规律（恢复系数 -> 反弹高度衰减）
- 难度：简单
- 样本数：约 100
- 目标：学习恢复系数越大，反弹高度越高、衰减越慢。

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0,0.3,0.5,0.8,1.0]

### 物体参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[0]
  - y：[0]
  - z：[0.9,1.2,1.6,2.0]
- initial_velocity：
  - x：[0]
  - y：[0]
  - z：[-0.4,0,0.4]
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[1.0]
- friction：[0.4]
- color：[red,blue,yellow,green]

### 采样约束
- restitution 为主变量，5 个取值均衡覆盖。
- 物体 restitution 固定为 1.0，使 effective_restitution 与地面 restitution 一致，便于标签解释。
- 标签中记录 effective_restitution，训练时优先使用该标签解释实际反弹。

## Level 4：水平位置无关性与水平抛体独立性
- 难度：简单
- 样本数：约 100
- 目标：验证 x/y 初始位置不影响竖直运动，并学习水平速度与竖直运动相互独立。

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0]

### 物体参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[-0.6,-0.3,0,0.3,0.6]
  - y：[-0.6,-0.3,0,0.3,0.6]
  - z：[1.0,1.4,1.8]
- initial_velocity：
  - 水平位置子任务：[0,0,0]
  - 水平抛体子任务：[(0.4,0,0),(-0.4,0,0),(0,0.4,0),(0,-0.4,0),(0.6,0,0),(-0.6,0,0),(0,0.6,0),(0,-0.6,0),(0.45,0.45,0),(-0.45,0.45,0)]
- initial_angular_velocity：[0,0,0]
- mass：[1.0]
- restitution：[0]
- friction：[0.4]
- color：[red,blue,yellow,green]

### 采样约束
- 50 个左右样本用于水平位置无关性：vx=vy=0，成组改变 x/y。
- 50 个左右样本用于水平抛体独立性：x=y=0，成组改变 vx/vy。
- 每组配对保持 z、vz、radius、mass、restitution 一致。

## Level 6：尺寸无关性（球半径不影响自由落体规律）
- 难度：复杂
- 样本数：约 150
- 目标：验证同一底部离地高度下，球半径不影响自由落体时间。

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0]

### 物体参数
- object_type：[sphere]
- radius：[0.18,0.22,0.28]
- release_clearance：[0.5,0.8,1.2,1.6,2.0]
- initial_position：
  - x：[-0.3,0,0.3]
  - y：[-0.3,0,0.3]
  - z：radius + release_clearance
- initial_velocity：
  - x：[0]
  - y：[0]
  - z：[-0.4,0,0.4]
- initial_angular_velocity：[0,0,0]
- mass：[0.5,1.0,2.0]
- restitution：[0]
- friction：[0.4]
- color：[red,blue,yellow,green]

### 采样约束
- radius 为被验证的无关变量，3 个半径均衡覆盖。
- 比较落地时间时使用 release_clearance，不直接使用球心 z。
- 对每个 release_clearance/v0z/mass 组合，尽量生成完整 radius 配对组。

## Level 7：形状泛化（球 vs 方块，竖直下落）
- 难度：复杂
- 样本数：约 150
- 目标：学习同一接触高度与初速度条件下，球和方块的竖直下落规律一致，并覆盖形状差异带来的碰撞表现。

### 地面参数
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0,0.3,0.6]

### 物体参数：sphere
- radius：[0.18,0.22,0.28]
- contact_offset：radius
- initial_position：z 分量 contact_offset + release_clearance
- initial_quaternion：[1,0,0,0]

### 物体参数：cube
- size：[(0.18,0.18,0.18),(0.24,0.24,0.24),(0.30,0.30,0.30)]
- contact_offset：size 的 z 分量 / 2
- initial_position：z 分量 contact_offset + release_clearance
- initial_quaternion：[1,0,0,0]

### 共享物体参数
- release_clearance：[0.5,0.8,1.2,1.6,2.0]
- initial_position：
  - x：[-0.3,0,0.3]
  - y：[-0.3,0,0.3]
- initial_velocity：
  - x：[0]
  - y：[0]
  - z：[-0.5,0,0.5]
- initial_angular_velocity：[0,0,0]
- mass：[0.5,1.0,2.0]
- restitution：[0.5]
- friction：[0.4]
- color：[red,blue,yellow,green]

### 采样约束
- object_type 为主泛化变量，sphere/cube 各约 75 个样本。
- shape 对比必须按 release_clearance、v0z、mass、restitution 配对。
- 尺寸使用近似等尺度配对：radius 0.18 对 cube 0.18，radius 0.22 对 cube 0.24，radius 0.28 对 cube 0.30。
