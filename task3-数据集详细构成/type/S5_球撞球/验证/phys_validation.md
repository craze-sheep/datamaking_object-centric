## 二、共用物理场景

- Ground: 8.0×6.0×0.08, frictionless（刻意设置，隔离碰撞物理）
- 两球初始 z=radius（刚好触地），无 z 向运动
- 球在摩擦less地面上滑动，碰撞前匀速直线运动
- 5 相机视角: [front, back, left, right, top]

### 碰撞物理公式

**对心碰撞**（等质量 m=1.0, 静止目标 B, e_eff = e_a × e_b）：

```
v_a_after = ½(1 - e_eff) × v0        // 运动球碰后速度
v_b_after = ½(1 + e_eff) × v0        // 目标球碰后速度
```

**非等质量对心碰撞**（m_r = m_b / m_a）：

```
v_a_after = (1 - e_eff × m_r) / (1 + m_r) × v0
v_b_after = (1 + e_eff) / (1 + m_r) × v0
```

**斜碰 d_min**（判断是否命中）：

```
d_min = | -(x_b - x_a)×sinθ + (y_b - y_a)×cosθ |
命中条件：d_min < r_a + r_b
```
