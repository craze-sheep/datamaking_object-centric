# Type1：球撞球参数配置

## 全局设置
- 视频时长：3s
- 分辨率：64 x 64
- 总帧数：36 帧
- 帧率：12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,back,left,right,top]
- 样本数口径：下文样本数指物理场景配置数；若每个配置渲染 5 个相机视角，视频数 = 样本数 x 5。
- 简单 level 样本数：约 80 个
- 复杂 level 样本数：约 120 个

## 通用固定项

### ground 参数
- object_type：[ground]
- PyBullet/Kubric 实现：static Cube
- size：[(8.0,6.0,0.08)]
- initial_position：[0,0,-0.04]
- initial_quaternion：[[1,0,0,0]]
- static：true
- mass：[1.0]
  - 注意：static=true 时，mass 不作为变化变量。
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0]
- lateralFriction：[0]
  - 说明：地面无摩擦是刻意设置，用于隔离两球碰撞物理。
- color：[gray]
- 其他属性：默认值

- friction：按 level 指定
- color：[red,blue,yellow,green]
- 其他属性：默认值

### sphere_b 参数
- object_role：target_ball
- object_type：[sphere]
- radius：按 level 指定
- initial_position：按 level 指定
- initial_quaternion：[[1,0,0,0]]
- mass：按 level 指定

- restitution：按 level 指定
- friction：按 level 指定

### 采样与标签
- PyBullet 可用性：当前 Kubric PyBullet wrapper 直接支持 Sphere/Cube；本任务只使用 Sphere 作为运动物体。
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 初始高度：sphere_a 的 z = sphere_a 的 radius，sphere_b 的 z = sphere_b 的 radius
- 避免初始穿透：两球初始中心距离 > sphere_a 的 radius + sphere_b 的 radius
- 通用标签：
  - first_contact_time
  - first_contact_frame
  - pre_collision_velocity_a
  - pre_collision_velocity_b
  - post_collision_velocity_a
  - post_collision_velocity_b
  - incident_speed_normal
  - separation_speed_normal
  - effective_restitution
  - momentum_before
  - momentum_after
  - kinetic_energy_before
  - kinetic_energy_after
  - scattering_angle_a
  - scattering_angle_b
  - final_position_a
  - final_position_b
  - final_linear_speed_a
  - final_linear_speed_b
  - final_angular_speed_a
  - final_angular_speed_b
  - ball_a_left_visible_area
  - ball_b_left_visible_area

目标：学习恢复系数越大，碰撞后两球法向分离速度越大。

### sphere_b 参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[0.55]
  - y：同 sphere_a 的 initial_position 的 y 分量
  - z：radius

- mass：[1.0]

- sphere_b 的 restitution 为主变量；sphere_a 的 restitution 固定为 1.0，使 effective_restitution 主要由 sphere_b 的 restitution 决定。
- 两球 y 坐标相同，保证对心碰撞。
- color 只作为视觉扰动，不与恢复系数绑定。

## [复杂] Level 6：入射角度与二维碰撞方向（非对心，不同二维入射方向）
目标：学习二维入射方向与目标球位置共同决定碰撞法线和散射方向。

### ground 参数
- 使用通用固定项。

### sphere_a 参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[-0.90,-0.75]
  - y：[-0.25,0,0.25]
  - z：radius
- initial_quaternion：[[1,0,0,0]]
- mass：[1.0]
- speed：[1.8,2.4]
- incident_angle_degree：[-30,-15,0,15,30]
- initial_velocity：speed * [cos(angle), sin(angle), 0]
- initial_angular_velocity：[0,0,0]
- restitution：[1.0]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### sphere_b 参数
- object_type：[sphere]
- radius：[0.22]
- target_y：[-0.20,0,0.20]
- initial_position：
  - x：[0.55]
  - y：target_y
  - z：radius
- initial_quaternion：[[1,0,0,0]]
- mass：[1.0]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0.8]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- incident_angle_degree 与 target_y 分层采样。
- 过滤两球轨迹最近距离 >= sphere_a 的 radius + sphere_b 的 radius 的 miss 组合。
- 采样器必须计算 d_min = |-(sphere_b 的 x - sphere_a 的 x) * sin(angle) + (sphere_b 的 y - sphere_a 的 y) * cos(angle)|，仅保留 d_min < sphere_a 的 radius + sphere_b 的 radius 的组合。
- angle=±30° 的 miss 比例较高，采样时优先保留 d_min < 0.40 的组合作为稳定命中样本。
- angle=0 且 target_y=sphere_a 的 y 为对心碰撞基线。
