# S3：单物体斜面滑动参数配置

## 全局设置
- 视频时长：3s
- 分辨率：64 x 64
- 总帧数：36 帧，12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,top,left]
- 样本数口径：下文数量按物理场景配置计算；若渲染 3 个视角，视频数 = 物理配置数 x 3。
- 简单 level：约 80 个物理配置
- 复杂 level：约 120 个物理配置

## 通用固定项

### ground 参数
- object_type：[ground]
- size：[(4.0,4.0,0.08)]
- initial_position：[0,0,-0.04]
- initial_quaternion：[[1,0,0,0]]
- static：true
- lateralFriction：[0.5]
- rollingFriction：[0.005]
- spinningFriction：[0.001]
- restitution：[0]
- color：[gray]
- 其他属性：默认值

### ramp 参数
- object_type：[ramp]
- size：[(2.4,1.0,0.12)]
- initial_position：[0,0,0.12 + 0.5 * size 的 x 分量 * sin(incline_angle)]
- initial_quaternion：由 incline_angle 生成，Kubric 格式 [w,x,y,z]
- static：true
- mass：[1.0]
  - 注意：static=true 时，mass 不作为变化变量。
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0]
- friction：按 level 指定
- rollingFriction：按 level 指定
- spinningFriction：按 level 指定
- color：[brown,gray]
- 其他属性：默认值

### 物体公共参数
- friction：[1.0]
- restitution：[0]
- initial_position：ramp_surface_point + contact_offset * ramp_normal
- initial_velocity：按 level 指定
- initial_angular_velocity：按 level 指定
- color：[red,blue,yellow,green]
- 其他属性：默认值
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 接触高度：
  - sphere：contact_offset = radius
  - cube：contact_offset = size 的 z 分量 / 2
  - cylinder upright：contact_offset = height / 2
  - cylinder lying：contact_offset = radius
- 通用标签：
  - slide_start_time
  - slide_start_frame
  - stop_time
  - stop_frame
  - travel_distance_on_ramp
  - displacement_vector
  - final_position
  - final_linear_speed
  - final_angular_speed
  - effective_slope_acceleration
  - effective_lateral_friction
  - rolling_transition_time
  - reached_ramp_bottom
  - is_static_at_end

## [简单] Level 1：斜面倾角的影响（theta -> 下滑加速度/静止临界）
目标：学习斜面倾角越大，沿斜面向下的重力分量越大，并覆盖静止临界附近样本。

### ground 参数
- 使用通用固定项。

### ramp 参数
- object_type：[ramp]
- size：[(2.4,1.0,0.12)]
- incline_angle：[0.12,0.22,0.30,0.38,0.46,0.56]
- initial_position：[0,0,0.12 + 0.5 * size 的 x 分量 * sin(incline_angle)]
- initial_quaternion：由 incline_angle 生成
- static：true
- mass：[1.0]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0]
- friction：[0.2]
- rollingFriction：[0]
- spinningFriction：[0]
- color：[brown,gray]
- 其他属性：默认值

### object 参数
- object_type：[cube]
- size：[(0.24,0.24,0.24)]
- ramp_s：[-0.65,-0.45,-0.25]
- ramp_y：[-0.2,0.2]
- initial_position：ramp_surface_point(s=ramp_s,y=ramp_y) + contact_offset * ramp_normal
- initial_quaternion：同 ramp 的 initial_quaternion
- mass：[1.0]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0]
- friction：[1.0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- incline_angle 为主变量，6 个角度均衡覆盖。
- ramp_s/ramp_y 只作为位置扰动，保证每个角度都有多位置样本。
- friction 固定为 0.2；0.12 作为唯一静止/临界以下样本，其余 5 个角度从慢滑到快滑均匀展开，避免多个低角度全静止冗余。
- theta=0.22 时 3s 内约滑行 1m，在 64px 画面中约 13px，作为刚过临界的可辨慢滑样本。
