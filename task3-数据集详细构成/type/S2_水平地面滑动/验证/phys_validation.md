## 二、各 Level 物理推导与合理性判断

### Level 1：滑动摩擦的定性影响 (mu -> 停止距离)

**当前设定**：cube, v0=2.0m/s, mu=[0.25,0.4,0.6,0.8,1.0], 12fps。

库仑摩擦下：

```
t_stop = v0 / (mu * g)
d_stop = v0^2 / (2 * mu * g)
```

| mu | t_stop | 12fps帧数 | d_stop | 判断 |
|:---:|---:|---:|---:|---|
| 0.25 | 0.816s | 9.8帧 | 0.816m | 可见 |
| 0.40 | 0.510s | 6.1帧 | 0.510m | 可见 |
| 0.60 | 0.340s | 4.1帧 | 0.340m | 可见 |
| 0.80 | 0.255s | 3.1帧 | 0.255m | 可见 |
| 1.00 | 0.204s | 2.4帧 | 0.204m | 勉强但可用 |

原先 mu=1.5/2.0/3.0 导致停止过程压缩到 1-2 帧的问题已修复：当前最高 mu=1.0，停止过程至少约 2.4 帧，总位移约 0.204m。✓

物理组合数：

```
mu(5) × x(3) × y(3) × color(4) = 180 → 需~80 ✓
```

### Level 2：初速度大小的影响 (v0 -> 停止距离)

**当前设定**：v0=[1.0,1.3,1.6,1.9,2.2,2.5,2.8,3.0]m/s，mu=[0.3,0.45,0.6]。

最低可见性由 v0=1.0、mu=0.6 决定：

```
t_stop = 1.0 / (0.6 * 9.8) = 0.170s = 2.0帧
d_stop = 1.0^2 / (2 * 0.6 * 9.8) = 0.085m
```

若相机视野约 2m 宽，64px 下每像素约 0.031m，则最低位移约 2.7px。原先 v0=0.5 导致总位移不足 1px 的问题已修复。✓

最高位移由 v0=3.0、mu=0.3 决定：

```
t_stop = 1.020s
d_stop = 1.531m
```

该组合用于拉开高速低摩擦样本，采样实现时应优先搭配居中初始位置，避免出视野。

物理组合数：

```
v0(8) × mu(3) × color(4) = 96 → 需~80 ✓
```

### Level 3：质量无关性验证

库仑摩擦中质量被约掉：

```
f = mu * m * g
a = f / m = mu * g
d_stop = v0^2 / (2 * mu * g)
```

因此相同 v0 与 mu 下，不同 mass 的停止距离一致。✓

物理组合数：

```
mass(5) × v0(3) × mu(2) × color(4) = 120 → 需~80 ✓
```

### Level 4：尺寸/接触面积无关性

**当前设定**：size=3档，v0=[1.0,1.4,1.8,2.2,2.6]m/s，mu=[0.3,0.45,0.6]。

理想库仑摩擦中接触面积不影响滑动减速度：

```
N = m * g
f = mu * N
a = mu * g
```

最低可见性由 v0=1.0、mu=0.6 决定，与 L2 相同：

```
t_stop = 0.170s = 2.0帧
d_stop = 0.085m ≈ 2.7px
```

物理组合数：

```
size(3) × v0(5) × mu(3) × color(4) = 180 → 需~80 ✓
```

原先 36 个名义组合支撑 80 样本的问题已通过增加速度点与 mu 扰动修复。✓

### Level 5：初速度方向与二维滑动

**当前设定**：speed=[1.5,2.0,2.5], direction=8方向，mu=[0.3,0.5]。

二维库仑摩擦向量形式：

```
a_vec = -mu * g * v_vec / |v_vec|
```

加速度大小与方向无关，位移方向跟随初速度方向。最低可见性：

```
speed=1.5, mu=0.5
t_stop = 1.5 / (0.5 * 9.8) = 0.306s = 3.7帧
d_stop = 0.230m
```

原先 low speed + high mu 在 2 帧内停止的问题已通过移除 mu=1.0 修复。✓

物理组合数：

```
speed(3) × direction(8) × mu(2) × color(4) = 192 → 需~120 ✓
```

### Level 6：球体滑动-滚动转换

**当前设定**：v0=[2.0,2.5,3.0]m/s，mu=[0.2,0.3]，rollingFriction=[0,0.01,0.03,0.05,0.1]。

实心球从纯滑动到纯滚动的转换时间：

```
t_trans = 2 * v0 / (7 * mu * g)
```

| mu | v0 | t_trans | 12fps帧数 |
|:---:|:---:|---:|---:|
| 0.2 | 2.0 | 0.292s | 3.5帧 |
| 0.2 | 2.5 | 0.364s | 4.4帧 |
| 0.2 | 3.0 | 0.437s | 5.2帧 |
| 0.3 | 2.0 | 0.194s | 2.3帧 |
| 0.3 | 2.5 | 0.243s | 2.9帧 |
| 0.3 | 3.0 | 0.292s | 3.5帧 |

原先 mu=1.0 导致转换小于 1 帧的问题已修复：当前最短转换约 2.3 帧，核心滑动到滚动过程可见。✓

滚动摩擦阶段以 v0=2.0 为例，转换后速度约 5/7 v0 = 1.43m/s：

| rollingFriction | 3s内效果 |
|:---:|---|
| 0 | 纯滚动近似匀速，对照组 |
| 0.01 | 速度变化约 0.29m/s，可作为弱滚阻 |
| 0.03 | 速度变化约 0.88m/s，明显 |
| 0.05 | 约 2.9s 停止，明显 |
| 0.10 | 约 1.5s 停止，明显 |

原先 rf=0.001/0.005 在 3s 内几乎无效果的问题已修复。✓

物理组合数：

```
radius(3) × mass(3) × v0(3) × omega_mode(2) × mu(2) × rf(5) × sf(约1-3)
```

即使过滤 spinningFriction > rollingFriction，组合空间也远大于 ~120。✓

### Level 7：圆柱滑动行为

圆柱姿态与速度方向决定纯滑动或可滚动行为：

| 姿态 | 速度方向 | 主要行为 |
|---|---|---|
| upright | x/y | 底面滑动 |
| lying_axis_x | 沿 x | 沿轴滑动 |
| lying_axis_x | 沿 y | 可绕轴滚动 |
| lying_axis_y | 沿 x | 可绕轴滚动 |
| lying_axis_y | 沿 y | 沿轴滑动 |

当前 radius、height、mu、rollingFriction 与速度方向均衡覆盖，能支撑姿态差异学习。✓

物理组合数：

```
upright:      r(3) × h(3) × mu(2) × rf(2) × v(2) = 72
lying_axis_x: r(3) × h(3) × mu(2) × rf(3) × v(2) = 108
lying_axis_y: r(3) × h(3) × mu(2) × rf(3) × v(2) = 108
基础组合合计 288，含颜色后远大于 ~120 ✓
```

## 四、最终结论

滑动参数配置当前物理上可用：12fps 下关键减速与滑动-滚动转换均至少有约 2 帧以上的观测窗口，低速亚像素位移问题已消除，L2/L4 样本多样性也已补足。采样器实现时应对低 mu + 高 v0 的长距离场景做初始位置约束，避免物体出视野。
