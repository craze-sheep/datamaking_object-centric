# S4：墙面反弹参数配置

## 全局设置
- 视频时长：3s
- 分辨率：64 x 64
- 总帧数：36 帧
- 帧率：12fps
- gravity：[0,0,-9.8]
- 单位：SI，m / kg / s / m/s / rad/s
- 相机角度：[front,top]
- 样本数口径：下文样本数指物理场景配置数；若每个配置渲染 2 个相机视角，视频数 = 样本数 x 2。
- 简单 level 样本数：约 100 个
- 复杂 level 样本数：约 150 个

## 通用固定项

### ground 参数
- object_type：[ground]
- PyBullet/Kubric 实现：static Cube
- size：[(10.0,5.0,0.08)]
- initial_position：[0,0,-0.04]
- initial_quaternion：[[1,0,0,0]]
- static：true
- mass：[1.0]
  - 注意：static=true 时，mass 不作为变化变量。
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0]
- lateralFriction：[0]
  - 说明：地面无摩擦是刻意设置，用于隔离墙面碰撞物理；本任务是摩擦less地面上的滑动-撞墙场景。
- color：[gray]
- 其他属性：默认值

### wall 参数
- object_type：[wall]
- PyBullet/Kubric 实现：static Cube
- size：[(0.10,5.00,1.20)]
- initial_position：[1.20,0,0.60]
- initial_quaternion：[[1,0,0,0]]
- static：true
- mass：[1.0]
  - 注意：static=true 时，mass 不作为变化变量。
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：按 level 指定
- friction：按 level 指定
- color：[gray,blue]
- 其他属性：默认值

### object 公共参数
- object_type：[sphere,cube]
- initial_position：按 object_type 设置接触高度，x 位于墙面左侧
- initial_velocity：按 level 指定
- initial_angular_velocity：按 level 指定
- mass：按 level 指定
- restitution：按 level 指定
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值
- PyBullet 可用性：当前 Kubric PyBullet wrapper 直接支持 Sphere/Cube；cylinder 不放入 S4 主设计。
- 采样方式：分层采样，主变量均衡覆盖，边界值优先覆盖。
- 无关性验证：除被验证变量外，其余动力学变量保持一致，尽量成组配对。
- 接触高度：
  - sphere：initial_position 的 z 分量 = radius
  - cube：initial_position 的 z 分量 = size 的 z 分量 / 2
- 通用标签：
  - first_wall_contact_time
  - first_wall_contact_frame
  - pre_collision_velocity
  - post_collision_velocity
  - incident_speed_normal
  - reflected_speed_normal
  - tangential_speed_before
  - tangential_speed_after
  - effective_restitution
  - rebound_distance
  - final_position
  - final_linear_speed
  - final_angular_speed
  - is_static_at_end

## [简单] Level 1：墙面恢复系数的影响（restitution -> 反弹速度比）
目标：学习墙面恢复系数越大，碰撞后法向反弹速度越大。

### ground 参数
- 使用通用固定项。

### wall 参数
- object_type：[wall]
- size：[(0.10,5.00,1.20)]
- initial_position：[1.20,0,0.60]
- initial_quaternion：[[1,0,0,0]]
- static：true
- mass：[1.0]
- initial_velocity：[0,0,0]
- initial_angular_velocity：[0,0,0]
- restitution：[0,0.3,0.5,0.8,1.0]
- friction：[0]
- color：[gray,blue]
- 其他属性：默认值

### object 参数
- object_type：[sphere]
- radius：[0.22]
- initial_position：
  - x：[-0.75,-0.55,-0.35]
  - y：[-0.25,0,0.25]
  - z：radius
- initial_quaternion：[[1,0,0,0]]
- mass：[1.0]
- initial_velocity：[(2.0,0,0)]
- initial_angular_velocity：[0,0,0]
- restitution：[1.0]
- friction：[0]
- color：[red,blue,yellow,green]
- 其他属性：默认值

### 约束
- restitution 为主变量，5 个取值均衡覆盖。
- 物体 restitution 固定为 1.0，使 effective_restitution 主要由墙面 restitution 决定。
- ground 的 x 尺寸加长，保证 e_eff >= 0.8 的高反弹样本在 3s 内仍留在地面范围内。
- x/y/color/wall 的 color 作为位置与视觉扰动，不与恢复系数绑定。
