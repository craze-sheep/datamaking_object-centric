### 单位：
- 长度：m
- 质量：kg
- 时间：s
- 线速度：m/s
- 角速度：rad/s
- 角度：rad

### 地面参数
- lateralFriction（滑动摩擦系数）
  - 含义：库仑滑动摩擦系数μ，表示两个接触面之间抵抗相对滑动的能力
  - 取值：[0,0.25,0.5,0.75,1,1.5,2,3]
- rollingFriction（滚动摩擦）
  - 含义：抵抗球体或圆柱体滚动的阻力矩，源于形变带来的能量损耗
  - 取值：[0,0.001,0.005,0.007,0.01,0.05,0.1,0.2,0.3,0.5]

-->
- spinningFriction（自旋摩擦）
  - 含义：抵抗物体绕接触法线原地旋转（自转）的阻力矩。
  - 注意：每个场景取值时中比 rollingFriction更小
  - 取值个数：9
  - 值：[0,0.003,0.005,0.008,0.03,0.08,0.18,0.28,0.48]

- restitution（反弹系数）
  - 含义：表示碰撞后相对速度与碰撞前相对速度的比值。
  - 取值个数：6
  - 值：[0,0.1,0.3,0.5,0.8,1]

- 其他属性：默认值

### 通用物体参数
- object_type（物体类型）：[sphere,cube,cylinder,ramp]

### 球：sphere
- radius（半径）：[0.18,0.22,0.28]
- initial_position（初始位置）
- initial_quaternion（初始姿态）：默认值 [1,0,0,0]
  - Kubric 格式：[w,x,y,z]
  - 注意：球体几何对称，初始姿态通常不作为变化变量。
- mass（质量）
- initial_velocity（线速度）
- initial_angular_velocity（角速度）
- restitution（恢复系数）
- friction（摩擦系数）
- color（颜色）
- 其他属性：默认值

### 方块：cube
- size（尺寸）：[(0.18,0.18,0.18), (0.24,0.24,0.24), (0.30,0.30,0.30)]
- initial_position（初始位置）
- initial_quaternion（初始姿态）：默认值 [1,0,0,0]
  - Kubric 格式：[w,x,y,z]
- mass（质量）
- initial_velocity（线速度）
- initial_angular_velocity（角速度）
- restitution（恢复系数）
- friction（摩擦系数）
- color（颜色）
- 其他属性：默认值

### 斜面：ramp / inclined_plane
- object_type（物体类型）：ramp
- size（尺寸）
- initial_position（初始位置）
- initial_quaternion（初始姿态）
  - Kubric 格式：[w,x,y,z]
- incline_angle（斜面角）
  - 单位：rad
- static（是否静态）：true
- mass（质量）
  - 注意：static=true 时，mass 不作为变化变量。
- initial_velocity（线速度）：[0,0,0]
- initial_angular_velocity（角速度）：[0,0,0]
- restitution（恢复系数）
- friction（摩擦系数）
- color（颜色）
- 其他属性：默认值

### 圆柱：cylinder
- radius（半径）：[0.16,0.20,0.24]
- height（长度）：[0.22,0.28,0.34]
- initial_position（初始位置）
  - 约束：若圆柱竖直放置，z > height / 2，避免初始状态与地面穿透。
- initial_quaternion（初始姿态）
  - Kubric 格式：[w,x,y,z]
  - upright（直立）：[1, 0, 0, 0]
  - lying（躺着）：[0.7071, 0, 0.7071, 0]
- mass（质量）
- initial_velocity（线速度）
- initial_angular_velocity（角速度）
- restitution（恢复系数）
- friction（摩擦系数）
- color（颜色）
- 其他属性：默认值
