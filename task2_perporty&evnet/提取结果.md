# task2: Kubric PyBullet 数据能力核对

## 结论

- Kubric 的 `PyBullet.run()` **直接返回**两类数据：每帧物体运动状态 `animation`，以及物理步级别的接触采样 `collisions`。
- 你写的 `Mass/Friction/Restitution/Static/Position/Quaternion/Linear Velocity/Angular Velocity` 基本判断正确，属于 Kubric/PyBullet 可直接拿。
- `Visibility/Depth/Optical Flow/2D BBox` 不是 PyBullet 输出；它们来自 Blender 渲染层或 segmentation 后处理。
- `3D BBox` 是 Kubric 根据物体几何和每帧 pose 计算，不能算 PyBullet 原生 contact 输出。
- `Collision` 原始数据可直接拿，但那是很多 contact samples；标注事件时要聚合连续 contact 区间。

## PyBullet 直接提供

- `animation`: position, quaternion, velocity, angular_velocity
  - 来源: `kubric-main/kubric/simulator/pybullet.py:273-309`
  - 说明: PyBullet.run() samples these once per rendered frame and returns them per PhysicalObject.
- `collisions`: instances, position, contact_normal, frame, force
  - 来源: `kubric-main/kubric/simulator/pybullet.py:279-299`
  - 说明: These are contact samples from every physics step where normal_force > 1e-6.
- `physical_object_attributes`: mass, friction, restitution, static, velocity, angular_velocity, segmentation_id
  - 来源: `kubric-main/kubric/core/objects.py:160-199`
  - 说明: These are Kubric PhysicalObject attributes used by the PyBullet backend.

## Kubric/Renderer 可提供，但不是 PyBullet 原生

- `instance_info`: positions, quaternions, velocities, angular_velocities, mass, friction, restitution, image_positions, bboxes_3d
  - 来源: `kubric-main/kubric/utils.py:159-184`
  - 说明: Convenience collector after simulation keyframes exist; bboxes_3d are computed from object geometry and pose.
- `scene_metadata`: resolution, frame_rate, step_rate, gravity, num_frames
  - 来源: `kubric-main/kubric/utils.py:132-142`
  - 说明: Scene-level metadata, not per-object physics state.
- `visibility_and_2d_bbox`: visibility_pixel_count, bboxes, bbox_frames
  - 来源: `kubric-main/kubric/post_processing.py:21-68`
  - 说明: Computed from rendered segmentation; not PyBullet-native.
- `renderer_layers`: rgba, segmentation, backward_flow, forward_flow, depth, normal, object_coordinates
  - 来源: `kubric-main/kubric/renderer/blender.py:140-150,275-298`
  - 说明: Blender render outputs; optical flow and depth live here, not in PyBullet.

| Mass / Friction / Restitution | 原生直接拿 | **正确** | 它们是 Kubric PhysicalObject 属性，也会被写入 PyBullet body 参数。 | `object_properties.mass/friction/restitution` |
| Static | 配置项记录 | **正确** | static 是 PhysicalObject 属性，决定物体是否参与动态仿真。 | `object_properties.static` |

| Position / Quaternion | 原生直接拿 | **正确** | PyBullet.getBasePositionAndOrientation() 被 Kubric 包装成 animation[obj]['position'/'quaternion']。 | `object_states.positions/quaternions` |
| Linear Velocity | 原生直接拿 | **正确** | PyBullet.getBaseVelocity() 第一项就是线速度。 | `object_states.velocities` |
| Angular Velocity | 原生直接拿 | **正确** | PyBullet.getBaseVelocity() 第二项就是刚体角速度；它不是 2D 轨迹转向代理。 | `object_states.angular_velocities` |
| Visibility | 原生直接拿 | **需要修正** | Kubric 可以从 segmentation 后处理得到可见像素数，但 PyBullet 本身不提供 visibility。 | `derived_from_render.visibility 或 visibility_ratio` |
| Depth | 标准输出 | **正确但不是 PyBullet** | depth 是 Blender renderer layer，不是物理仿真器输出。 | `render_layers.depth` |
| Optical Flow | 标准输出 | **正确但当前示例未保存** | Kubric Blender renderer 支持 forward_flow/backward_flow；当前快照对应的生成脚本只请求 rgba/segmentation/depth。 | `render_layers.forward_flow/backward_flow` |
| 3D BBox | 标准输出 | **需要修正** | Kubric 可以用 instance.bbox_3d/get_instance_info 逐帧计算；不是 renderer 默认数组，也不是 PyBullet contact 输出。 | `object_states.bboxes_3d` |
| 2D BBox | 未单独列为选中项 | **派生** | 由 segmentation mask 后处理得到。 | `derived_from_segmentation.bboxes_2d` |
| Acceleration | 简单计算 | **正确** | 由相邻帧 velocity 差分得到，推荐用 3D velocity 而不是 2D mask 中心。 | `derived_motion.accelerations` |
| Speed / Angular Speed | 简单计算 | **正确** | 分别是 velocity 和 angular_velocity 的模长。 | `derived_motion.speed/angular_speed` |
| Collision | 原生直接拿 | **一半正确** | PyBullet 原生给 contact samples；如果标注 Collision event，应把连续 contact segment 的起点视为碰撞瞬时事件。 | `pair_events.collision_events` |
| Contact | 简单推导 | **正确** | 由 collision/contact samples 按 pair 聚合成持续区间。 | `pair_events.contact_intervals` |
| Strong Collision | 简单推导 | **正确** | 由 contact force 阈值判断。 | `pair_events.strong_collision_events` |
| Stop / Start Moving / Sliding / Falling / Spinning | 阈值或多条件判定 | **正确** | 这些都是从速度、角速度、接触状态派生的 object-level events。 | `object_events.*` |

## 需要修正你原表述的地方

1. `Visibility` 不应写成 PyBullet 原生直接拿；应写成 Kubric segmentation 后处理。
2. `Depth` 和 `Optical Flow` 是 Blender renderer layer，不是 PyBullet。
3. `3D BBox` 是 Kubric 几何+pose 计算；可以直接用 `get_instance_info` 拿，但来源不是 PyBullet contact。
4. `Collision` 可以从 PyBullet contact samples 直接拿原始数据，但事件标签需要聚合，否则一次持续接触会被记成很多次碰撞。
5. 当前 task2 输入快照的 `labels.json` 还没有保存 `position/quaternion/velocity/angular_velocity/bboxes_3d`，下一步应补到生成脚本。
